**行业池**（周频，申万一级 31 行业）：
```
L0  变盘指数 T′ < 0（收敛）→ 启用行业池；T′ ≥ 0 → 行业池为空
```

**主档不做 L2 稳定性过滤**（用户未明确要求；`POOL_FILE=industry_pool_l2.parquet` 可切对照，本次未跑）。

## 结论

### ❌ 更新六失败：行业池过滤把收益砍掉 60%

**+62.6% vs W2 +186.7%（−124.1pp），vs 无池的 ③（−96.5pp）。Sharpe 0.289，回撤 −32.3%。**

**全指标劣化**：
- 单笔均值 3.74% → **1.76%**
- 交易胜率 35.9% → **31.3%**
- **肥尾率 8.2% → 5.8%** ← **把大赢家滤掉了**
- 失败率 64.1% → 68.7%

### 🔍 为什么 —— 三重过滤导致过度收紧

更新六的行业池本身就是**双重择时**：

```
MA200（开 2,755 日，97%）          ← W2 原有
  ∩ 变盘指数 T′<0（39.5% 的时间）
  ∩ 240日动量前 3 行业（3/31 的空间）
  ────────────────────────────────
  有效交易日 1,118 / 2,828（39.5%）
```

**而 W2 的 v4 突破信号本身已经是一个很强的筛选**（13,833 个事件 → 468 笔成交）。再叠一层行业硬过滤 → **过度收紧，把最好的机会一起滤掉**（肥尾率掉 2.4pp 就是证据）。

### 📌 这已经是第三次撞同一堵墙

| 变体 | 过滤方式 | 相对对照 |
|---|---|---|
| **更新二** | 只做行业排名前 5（31 取 5） | **−31.1pp** |
| **更新六** | T′<0 + 240日动量前 3（31 取 3，且只 39.5% 时间） | **−96.5pp** |
| （对照）更新一 | 双过滤（MA200 ∩ T′<0） | −65.6pp（vs W2） |

**每次都验证同一条定律：**

> **排序 ≫ 开关**（analysis_014 三杠杆归因）

**把行业信息从"排序键"降级成"硬阈值"，收益就掉。** 掉多少取决于阈值多硬 —— 更新六的阈值最硬（时间 × 空间双重），掉得最多。

### 🔑 与用户那个策略的真正差异

| | 用户的策略 | 本更新 |
|---|---|---|
| **选股（L3）** | **反转 + 低关注度**（买超跌） | v4 **突破**（买强势） |
| **行业池的作用** | **决定"买哪个行业"**（方向） | **额外的一层硬过滤** |

**关键：行业池在"买超跌"框架里是方向，在"买突破"框架里只是过滤器。**

因为：
- 买超跌策略**需要**行业层告诉它"哪个行业在风口上"（否则买的是全市场超跌，可能是下跌趋势中的死猫跳）
- 买突破策略的信号**本身已经筛过一遍**（能突破的票已经反映了行业景气），再加行业过滤 = 重复筛 + 过度收紧

**这解释了为什么同一个行业池，在那边有效、在这边有害。**

## 下一步建议

| 方向 | 说明 |
|---|---|
| **A（推荐）. 承认分岔** | 行业池需要"买超跌"的 L3 配合才有价值。要么搭那套策略，要么放弃行业池这条线 |
| **B. 行业池降级为排序键** | 不做硬过滤，而是把"是否在池内"作为 COMBO score 的**加分项**（如 +0.5）。这才是"排序 ≫ 开关"的正确用法 |
| **C. 只保留 T′<0 的时间过滤、去掉空间过滤** | 拆开看：时间维度（T′<0）与空间维度（前3行业）各自贡献多少 —— 但更新一/四已测过 T′<0 作闸门是 −65.6pp |

**建议 A 或 B。** 六轮已把"把行业信息接进 W2（买突破）框架"这条路走死。
