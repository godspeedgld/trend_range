# 策略思路 — strategy_001（沪深300指数增强·平台突破）

## 研究方向
时序 + 个股平台突破 + 股指增强（指数增强策略）

## 交易规则（v1）

### 1. 每日收盘操作
- 1.1 计算满足开仓条件的股票，放入**开仓池**
- 1.2 计算持仓股票是否满足平仓条件，满足放入**平仓池**

### 2. 每日开盘操作
- 2.1 将所有平仓池股票平仓
- 2.2 平仓后若持仓 < 最大持仓数（默认 **n=10**），从开仓池选入开仓，仓位按仓位规则执行，开仓后从开仓池剔除；选入优先级按优先级规则

### 3. 开仓规则
- 3.1 平台突破方法：转折点识别算法 + HSAR 阻力位算法 + 价量信息增强（参考 cj-plateau-break 复现）
- 3.2 满足开仓条件放入开仓池

### 4. 平仓规则
- 4.1 突破后股价发生 **10% 滚动回撤**
- 4.2 持仓时间大于 **45 天**

### 5. 仓位规则
- 5.1 投入资金始终保持不变（不将利润用于投资——每笔投入固定金额，浮盈不再投）
- 5.2 每只股票占用比例 **1/n**，n 为最大持仓数

### 6. 股票池
- 6.1 指数增强策略：每日收盘计算的可选股票**只在当前指数成分股中**（查 index_component 成分表取当日沪深300成分，剔除已持仓）

## 铁律：严禁使用未来数据
- 每日收盘决策只用 ≤t 日数据；执行在 t+1 开盘
- 股票池用**当日**成分股（index_component 当日记录），严禁用历史全量成分并集或期末成分

## 参数汇总
| 参数 | 值 |
|------|-----|
| n（最大持仓） | 10 |
| 突破幅度 | 3%（收盘 > 阻力位×1.03） |
| 滚动回撤 | 10% |
| 最大持有 | 45 天 |
| 成本 | 双边 15bps（引擎默认） |
| 转折点 | N=20, K=1, P=4 |
| HSAR | M=10, Q=2 |
| 回测区间 | 2017-01 ~ 2021-12（2016 作暖期） |

## 实现映射（local_portfolio_backtest 5 接口）
| 规则 | 接口 |
|------|------|
| 3 开仓规则 | `entry_signal(hist_df)`：转折点+HSAR+突破3%+当日成分过滤 |
| 4 平仓规则 | `exit_check(entry_info, hist_df)`：回撤10%或45天 |
| 开仓池维护 | `pool_invalidate(hist_df, signal_date)`：超时/回撤剔除 |
| 2.2 优先级 | `select_order(open_pool)`：突破时间最近优先 |
