# 策略报告 — strategy_004（豆粕期货·平台突破 + 1×ATR 止损）

## 思路
平台突破算法（迭代一~三原样）移植到**豆粕主力连续**（本地 k_data.db，2000-07~2026-06，
6293 根换月平滑 K 线），时序 CTA 引擎（local_backtest），突破开仓 + **1×ATR 静态止损**，
无 45 天/10% 回撤规则。26 年全期测试。

## 回测结果（2000-07 ~ 2026-06）

| 指标 | 值 |
|------|-----|
| 总收益 | **-4.3%**（NAV 0.957） |
| 年化收益 | -0.2% |
| Sharpe | **-0.02** |
| 最大回撤 | -39.2% |
| 交易数 | **8 笔**（26 年） |
| 交易胜率 | **0%**（8 笔全亏，平均 -3.57%） |
| 平均持仓 | 59.5 天 |
| Profit Factor | 1.01（日频口径） |

分年：仅 2022（+34.1%）、2023（+13.5%）贡献正收益；2004/2010/2012/2013/2014/2016/2020/2021 均小亏；2024 -17.7%。

## 分析：为什么失败

**① 信号稀疏且集中**：26 年仅 198 个突破信号日（~8/年），聚成 10 轮行情
（2004 大豆牛市、2010/2012/2013/2014 美豆天气行情、2016、2020-21、2022 三轮）。
平台突破的"前1/3高位箱体 + 突破3%"参数是为股票季频行情设计的，豆粕期货
年度级行情少、且 3% 阈值滤掉了大量中等级突破。

**② 1×ATR 静态止损结构性不利**：
- 止损固定在入场价 − 1×ATR（不随盈利上移）；入场在突破次日开盘（价位已高）
- 豆粕 ATR(14) ≈ 价格 1.5~2%，即止损距离仅 ~2%——正常震荡就能打掉
- 8 笔全亏：突破后回调 2% 即出局，趋势没吃到；平均持仓 59.5 天说明出场后
  行情往往还延续（但止损已触发无法重入——信号簇早结束）

**③ 每轮行情只成交 1-2 次**：止损出场后信号簇（30 天左右）已过，无法重入，
26 年 198 个信号日只转化为 8 笔交易。

**结论**：**股票调参的平台突破 + 1×ATR 静态止损在豆粕上不成立**——不是算法错误，
是参数与止损结构不适配商品期货的波动结构（迭代一~三的胜率依赖"10%回撤+45天"
的宽止损/长持有，1×ATR 太紧）。

## 改进建议
1. **止损放宽**：k=2~3×ATR 或改吊灯式（atr_chandelier，随 since_high 上移）——让利润奔跑
2. **突破阈值降低**：break_pct 3%→1~1.5%（适配期货波动），预期信号数 3-5 倍
3. **加防闪烁重入**：止损出场后同趋势内允许重入（迭代一的 5 日池语义）
4. **多品种分散**：单品种信号太稀，扩到 76 品种全市场（本地数据已备）
5. **加量价过滤**：迭代二的过滤在股票上提升胜率 4pp，期货上可测试
