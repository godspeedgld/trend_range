# 策略思路 — strategy_004（豆粕期货·平台突破 + 1×ATR 止损）

承接 strategy_003（平台突破算法不变），迭代四为**跨市场移植测试**：股票组合 → 单一商品期货。

## 迭代变化（相对迭代三）

| 项 | strategy_003 | strategy_004 |
|----|-------------|--------------|
| 标的 | 沪深300成分股组合（最多10只） | **豆粕主力连续（单一期货 m）** |
| 数据 | 宽表面板 2015~2026.8 | **本地 k_data.db 日线 2000-07 ~ 2026-06**（换月平滑连续价，6293 根） |
| 引擎 | local_portfolio_backtest（组合池） | **local_backtest（时序 CTA 事件驱动，无多仓位）** |
| 开仓 | 突破+量价过滤，次日开盘 | **平台突破即开仓**（t 收盘确认 → t+1 开盘成交，引擎语义） |
| 平仓 | 回撤10% / 45天 | **1×ATR 静态止损**（入场价 − 1×ATR，日内 low 命中即成交，跳空取开盘） |
| 方向 | 多头 | 多头（allow_short=False） |

## 保持不变
- **平台突破算法**：转折点 N20/K1/P4 + HSAR M10/Q2 + 突破 3% + LOOKBACK 252（与迭代一~三逐参数一致）
- 成本：15bps 手续费 + 5bps 滑点

## 铁律：严禁未来数据
- 信号只用 ≤t 数据（转折点/阻力位在 252 日窗口内计算，无未来）

## 参数汇总
| 参数 | 值 |
|------|-----|
| 转折点 / HSAR / 突破 | N20 K1 P4 / M10 Q2 / 3% |
| LOOKBACK | 252 |
| 止损 | 1×ATR(14)，静态（atr_static） |
| 成本 | 20bps 单边（15+5） |
| 回测区间 | 2000-07 ~ 2026-06（26 年全期） |

## 实现映射（local_backtest 接口）
| 规则 | 接口 |
|------|------|

| 仓位 | `sizing fixed`（满仓 pos=1） |
