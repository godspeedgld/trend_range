## 数据（宽表面板，按 warehouse-playbook 宽表模式）

```sql
-- v_stock_panel：stock_bar1d 锚表 LEFT JOIN stock_valuation USING (instrument, date)
SELECT date, instrument, open, high, low, close, volume, amount, turn,
       total_market_cap
FROM v_stock_panel ORDER BY instrument, date;
```
- 锚表唯一：以 `stock_bar1d` 为骨架，估值表补市值列，停牌日留 NULL 不丢行
- 覆盖：668 只沪深300历史成分 × 2015-01-05 ~ 2026-08-21，市值 100% 覆盖
- 市值变量：LnCap = ln(total_market_cap)；CapVol5d/20d/45d = 市值滚动标准差

## 量价增强 v2（26 变量，其余同迭代二）
- 半年节点 t：用 `<t` 已实现样本（ret45_date < t，排除 t-45~t-1 防前视）逐步回归选变量（<260 放弃沿用上期），
  变量确定后用过去 500 交易日回归固定系数
- 节点 t 当日仍用上期，t+1 生效
- 运行时查表：突破日查 EVENT_MAP + 26 变量固定系数拟合 45 日收益 > 0 → 有效突破
- 无有效节点期等同迭代一（不设过滤）

## 铁律：严禁使用未来数据
- 突破检测只用 ≤t 数据；样本只用 ret45_date < t 的已实现突破
- 执行在 t+1 开盘；股票池用当日成分（index_component 当日记录）
