## 量价信息增强（长江研报 §1.4，26 变量回归筛选）

本地无市值数据 → 市值类 4 变量忽略，用 **22 个量价变量**（换手率7 + 成交额6 + 动量3 + 波动率3 + 均线偏离3）。

### 预计算（shared/vol_enhance.py，一次性，缓存 parquet/json）
- **突破事件表**：每窗口（与迭代一同算法）检测平台突破，记录 `{date, symbol, 22变量, ret45, ret45_date}`；
  变量只用 ≤t 数据；ret45 = 突破后 45 交易日收益（事后标签），ret45_date = 标签实现日
- **半年节点计划**：每 126 交易日一个节点

### 半年节点 t（用 <t 数据，防前视）
1. **已实现样本** = 事件表 `ret45_date < t`（排除 t-45~t-1 未实现突破）
2. **变量选择**：z-score 后标准逐步回归（前向+后向，p 进出 <0.05，不做分类平衡）；
   样本 < 260 → **放弃本次选择，沿用上期变量集**
3. **固定系数**：变量确定后用过去 500 交易日已实现样本（同样排除未实现尾部）回归系数，
   变量与系数一并固定，**不再每日重算**
4. **生效**：节点 t 当日仍用上期节点，新节点 t+1 生效

### 运行时（查表执行，无逐日回归）
每日收盘遇突破股票 → 查预计算变量 → 用当前节点固定系数拟合 45 日收益 →
**拟合收益 ≤ 0 → 假突破，不入开仓池**；> 0 → 有效突破。

- 无有效节点期间（样本不足 260，首个有效节点 2017-07-24 之前）→ **不设过滤**，突破直接入池（等同迭代一行为）

## 铁律：严禁使用未来数据
- 突破检测只用 ≤t 数据；变量选择/系数回归只用 `ret45_date < t` 的已实现样本（t-45~t-1 突破排除）
- 执行在 t+1 开盘；股票池用当日成分（index_component 当日记录）
