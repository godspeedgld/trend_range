# 策略报告 — strategy_002（沪深300指数增强·平台突破 + 量价信息增强）

## 思路
承接 strategy_001（平台突破开仓 + 回撤10%/45天平仓 + 1/n 等权）。迭代二**只加开仓过滤**：
用长江研报 §1.4 的量价信息增强（22 变量逐步回归，剔市值 4 类）判定突破真假——拟合 45 日收益 ≤ 0 判假突破不入开仓池。变量与系数**每半年节点固定**（预计算 + 查表执行），无逐日重算。

## 量价增强实现要点（shared/vol_enhance.py，预计算 + 查表）

- **突破事件表**：每窗口（与迭代一逐行同算法）转折点+HSAR+突破3%+当日成分，预计算 22 变量 + 45日收益 + 实现日，缓存 parquet
- **半年节点**：样本 `ret45_date < t`（排除 t-45~t-1 未实现突破，防前视）；<260 放弃沿用上期；z-score 标准逐步回归（p 0.05 进出）选变量，过去 500 交易日回归**固定系数**
- **生效**：节点 t 当日仍用上期，t+1 生效；首有效节点 2017-07-24，此前无过滤器（等同迭代一）
- **运行时**：突破日查表 → 固定系数拟合收益 > 0 → 有效突破

## 分析

**✅ 过滤机制完全复现论文**：样本级判别力极强——保留组（63%）45日收益均值 +3.89%（胜率53.7%），剔除组（37%）-3.24%（胜率33.3%）。交易级胜率 38.4%→41.5%、单笔收益 +1.06%→+1.51%、最大回撤 -12.1%→-10.3%，与论文"筛选后胜率 41.18%→45.65%、回撤减小"方向一致。

**❌ 但总收益下降 -10.6pp**，根因有二：
1. **砍掉大尾巴赢家**：被过滤的 223 笔中位数 -3.89%（多数是输家），但平均 +0.45%（含 +122% 最大赢家）。回归给高波动/高换手的暴涨突破打低分，2019/2021 动量主导年份（it1 超额主力）被系统性剔除
2. **交易数减少 + 现金拖累**：340 vs 414 笔，持仓利用率 7.54→7.11

即：过滤**提高了命中率、降低了波动**，但在沪深300+2017-2021（核心资产牛、动量领涨）口径下，迭代一的高收益恰恰高度依赖被砍掉的高飞尾部——"提高成功率"与"保住大赢家"在此口径下不可兼得。

## 偏差与局限
- 无市值数据 → 市值类 4 变量忽略（论文含 LnCap 等）
- 本地数据至 2021，未覆盖论文 2022-2026
- 预测目标为 45 日持有收益，而策略实际以回撤 10% 提前离场，两者不完全一致
- 节点样本用全部已实现突破（历史），系数用过去 500 日；未做样本外/滚动验证

## 改进建议
1. **放宽阈值**：拟合收益 > 0 过于严格，试 > -σ 或分位数阈值，保留更多尾部
2. **换目标**：以"持仓内实际离场收益"（回撤/45日规则模拟）为回归标签，而非纯 45 日持有收益
3. **节点前无过滤期**：首节点前 7 个月等同迭代一，可考虑用更早数据（如 2015 起）提前累积样本
4. **月度/季度重选**：半年重选在动量市可能滞后，试更短周期
5. **逐年归因**：2018/2021 过滤正确剔除输家但总收益仍差，深挖池动态（过滤改变选择轨迹）
