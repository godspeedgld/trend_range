# 分析记录 — analysis_004

## 更新一（新成败规则：加 20 天窗口 + 收益率判据；窗口字段落盘）

**原因**：生成版规则无时间上限，长期横盘信号挂 pending 不计（实测老信号仅 5 个 pending，影响可忽略）。用户改定新规则引入 20 天窗口，使"横盘不涨"也算失败，更贴近实盘资金占用成本；并要求把窗口数据落盘，后续规则变更只重判不重跑 v2.7。

**内容**（analysis.py 更新，规则替换）：
1. 基准=突破次日开盘；观察窗口=t+1~t+20 共 20 个交易日
2. **失败**：窗口内最低 < 基准×0.95（dip5），**或** 第 20 日收益 < 0（ret20_neg）
3. **成功**：窗口内未破 −5%，且（第 20 日收益 > 0（ret20_pos）**或** 窗口内最高 > 基准×1.10（high10））
4. 前向不足 20 根：dip5 可判则判，否则 pending_nofwd；未破且收益恰 0 → pending_flat
5. **明细新增落盘字段**：base / min_low_20 / max_high_20 / close_20 / ret_20 / min_low_inf / max_high_inf / first_dip_date / first_high_date / reason——任意后续规则变更**直接对明细重判**，不再重跑 7 分钟 v2.7 扫描

**result**（668 只，2017~2026-08，8429 次突破）：
- **总体：已判定 8327 | 成功 3011 | 失败 5316 | 成功率 36.2%**（vs 生成版无限窗口 39.7%，**-3.5pp**）

**分析**：
- 20 天上限主要"没收"了原本靠第 20 天后慢涨兑现的成功（2020/2021 结构牛慢涨年降幅最大 -9.1/-6.2pp；2019 快牛年几乎不变 -0.8pp）——**新规则惩罚慢兑现、奖励快兑现**
- 失败主力仍是 dip5（87.8%），ret20_neg 只补刀 12.2%：多数失败是"真跌破"而非"横着不动"
- 成功率 36.2% 进一步远离 50%：在 ±10%/−5% 不对称盈亏比下，信号自身 alpha 更显不足；结论不变——需市况/横截面过滤或配合离场规则（strategy_005 回测验证）

## 生成

**main_idea**：评估 analysis_003 锁定的算法 **v2.7 向上突破信号的真实成功率**——全市场沪深300 历史成分（668 只），2017 至今。规则（用户指定）：基准=突破后**次日开盘价**；失败=此后最低价 < 基准×0.95；成功=此后最高价 > 基准×1.10（先触发先生效，同日双触发按失败优先）；数据末尾未触发=pending 不计。逐股跑 v2.7 → 所有 break_up 事件 → 逐次判定 → 明细落盘（parquet+csv）→ 汇总体/年度/按标的统计。

**观察**：
- 39.7% 成功率 < 50%：突破后 10% 目标与 5% 止损的不对称（2:1 盈亏比）下，胜率 40% 附近为随机基准上下的水平；**信号本身无显著 alpha**，与 strategy_001~003 回测（修复 bug 后年化~4%）互相印证
- 强牛市年成功率明显高（2019 51.9%、2025 45.4%），熊市/震荡年低（2018 27.5%、2026 至 8 月 31.2%）——**成功率是市场 beta 的函数**，纯信号维度不滤市况的话质量随市况漂移
- 标的间差异大（14%~62%），未来可用行业/波动率/市值分层统计（明细已落盘，直接 groupby 即可）
