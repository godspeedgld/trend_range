# 分析记录 — analysis_005

## 更新二（回朴素：4 个逻辑特征 + OLS 线性）

**原因**：用户判断机器学习过滤提升有限（更新一 +2.3pp 未达显著），改走"朴素路线一点一点加"：先从特征入手，4 个有逻辑的加工特征 + OLS 线性模型（长江原方法形态，20 日窗口版）。

**内容**：
1. 特征 4 个（全为信号时可知）：TurnDecay=(TurnMean5d−TurnMean20d)/TurnMean20d×100（用户逻辑：换手衰减好）；AmtDecay=(AmtMean5d−AmtMean20d)/AmtMean20d×100（逻辑：量增好）；VolDecay=(Vol5d−Vol20d)/Vol20d×100；PricePctile60=收盘价 60 日分位（逻辑：低位突破好）
2. 模型 sklearn LinearRegression（OLS 含截距），**y=ret_20（20 日前瞻收益%）**；训练=生效半年 H 前推 1 年（[H−12月,H)，无验证窗）；score>0 → 有效保留
3. 特征大表重建（+4 列，含 PricePctile60 rolling rank）；滚动/成分过滤/输出同前（test 2018H2~2026H2 可比）

**result**（成分内 test 期 3424 信号）：
- **总体：保留 57.7% → 成功率 37.8% vs 37.4% = +0.4pp，无效**
- **模型退化为市场回声**：截距 −3.7~+8.4 吸收训练年市场涨跌 → 保留率 0%~100% 摆动（M1/M2 训练于熊市 keep=1%/0%；M3~M5 训练于牛市 keep=98~100%；M14~16 同理 84~96%）
- train_R2 仅 0.005~0.036；test 期 score 与实际 ret20 相关 |r| 多 <0.07（最大 0.19）
- **系数符号高度稳定（本次最有价值发现），但与用户逻辑预期相反**：
  - TurnDecay：**15/17 模型为正**（至 +0.45）→ 换手**上升**的突破更好（预期衰减好 ✗）
  - AmtDecay：**16/17 模型为负**（至 −0.42）→ 成交额**萎缩**的突破更好（预期量增好 ✗）
  - PricePctile60：12/17 弱正（~+0.03）→ 低位突破并未更好（与 004 回撤分桶倒钟形一致：线性项≈0）
  - VolDecay：符号翻转、幅度小 → 无信息
- TurnDecay⁺ & AmtDecay⁻ 近镜像组合 ≈ "近期价格已跌"（价跌→成交额缩，换手份额仍升）——**实为低位/反弹因子**，与 004 发现（强熊反弹位成功率最高 41.5%、追高最差 13.8%）同源

**分析**：
- OLS+截距在时序滚动下天然退化：截距=训练期市场均值收益，score>0 阈值变成"去年是牛市吗"开关——过滤机制失效，但**系数符号读数仍然有效**（横截面信息未被截距污染）
- 朴素路线的第一个实锤：**"换手衰减好、量增好、低位好"三个直觉两个反了**——数据支持的是"价跌量缩后的突破"（反弹语境），而非"放量突破"
- 若继续：**y 按期去均值**（截面 demean 或减市场同期收益）后再 OLS，截距归零、score 变纯横截面倾斜，才是干净的过滤信号

**补充检验（信号原始期望 vs 随机入场，本分析的收尾定论）**：
- v2.7 信号（成分内 test 期 3424 个）：平均 20 日收益 **+1.08%**（中位 +0.01%）
- **对照：同期全面板任意日随机入场（122 万样本）：+1.10%**——**信号期望 = 市场平均，零超额**
- 分标签：a 类 −4.79% / b 类 +3.34% / c 类 +14.49%（右偏：均值靠 c 类赢家拉起）
- 年度期望：2019 +4.4%、2020 +3.6%（牛市年），2021~2023 连续为负——期望完全随市场摆
- **定论：过滤无效的根因是信号本身无超额**——v2.7 突破在沪深300成分上统计上与随机入场不可区分；三轮过滤（树/LGBM/OLS）救不了没有 alpha 的信号。可保留的残余发现：追高过滤（前 20 日涨 ≥15% 剔除，约 +2~3pp）与"反弹语境"系数符号
- **年度超额分解（信号 vs 同年随机入场，pp）**：2019 +1.39 / 2020 +0.81（普涨快牛有真实超额）；2021 −1.51 / 2022 −0.61 / 2023 −0.63（阴跌震荡跑输随机）；2025 −0.80（**慢牛也不行**）；差值年均 −0.07pp、5/9 年为正——**"牛市可以熊市不好"不精确：只有普涨快牛可以，结构牛/慢牛同样跑输**

## 更新一（模型换 LightGBM + 训练窗 2 年 + 剔除市值特征）

**原因**：生成版诊断确认单棵决策树**高偏差为主**（最优容量 test macroF1 顶格 0.51、准确率不敌多数类基线；容量放开 train=1.0/test 掉 → 方差次要）。LightGBM 为 boosting（顺序拟合残差降偏差）+ 多树集成（部分降方差），理论上对症；用户指定三项调整：模型换 LightGBM、训练窗 1 年→2 年、剔除市值类特征（LnCap/CapVol{5,20,45}d，26→22 特征），其余不变。

**内容**：
1. LGBMClassifier 网格：num_leaves{7,15,31}×n_estimators{100,300}×lr{0.05,0.1}×min_child_samples{20,50}×class_weight{None,balanced}（48 组合），val macroF1 选优
2. train = [H−30月, H−6月)（2年），val/test 半年滚动不变（2018H2~2026H2 共 17 模型）
3. 环境坑：lightgbm 4.7.0 在 Windows 原生崩溃（access violation）→ **降级 4.6.0 解决**（4.5.0 与 sklearn 1.9 不兼容）；n_jobs=1 稳妥
4. 特征大表 feature_panel.parquet 复用（仍全算 26 列，仅模型输入剔除市值 4 列）

**result**（成分内 test 期信号 3471，2018H2~2026H2）：
- **总体：保留 1167（33.6%）→ 保留后成功率 39.7% vs 全量 37.4% = +2.3pp**（生成版单棵树为 -0.7pp，方向转正）
- 17 模型 test acc 0.357~0.624、macroF1 0.235~0.473；train_acc 常 0.9~1.0（boosting 拟合狠，靠 val 选参压方差）
- 半年度提升 **11/17 为正**：2020H1 +20.8（留 23% 信号成功率 64.6%）、2024H2 +14.7、2022H2 +13.3；负值最大 2022H1 -12.0、2019H1 -6.6
- 特征重要度（gain）：**Vol20d/Vol45d 仍主导**（单模型最高 0.18），次 AmtRatio45d、Ret5d、PriceMA{5,20,45}Dev——特征族与生成版一致，boosting 用得更充分
- 统计显著性（诚实口径）：保留组 SE≈1.4pp，+2.3pp ≈ 1.6σ——**方向性证据，未达 95% 显著**；11/17 半年正（符号检验 p≈0.23）

**分析**：
- 换 boosting 确实把过滤精度做正了（更挑剔：保留率 48.3%→33.6%，留下来的更准），与"降偏差"的预判一致；但提升幅度温和且不显著——**特征信息量的天花板仍在**（Vol 族重复主导说明模型反复啃同一块骨头）
- 训练窗 2 年让样本翻倍（n_train 407~942），后期模型更稳
- 若要继续抬升：加市场层特征（指数动量/宽度/市场波动）仍是首选实验；或把 LightGBM 的预测概率作为连续过滤阈值（而非硬三分类）调保留率-精度曲线

## 生成

**main_idea**：找能提高 v2.7 成功率的因素——用长江证券《平台突破》表4 的 **26 个价量特征**（换手率7/成交额6/动量3/波动率3/市值4/均线偏离3）训练**决策树分类树**（非长江的线性逐步回归），滚动过滤 v2.7 突破信号。标签三类（同 analysis_004 更新一规则，成功拆两类）：a=窗口20日内破基准-5%或20日收益<0；c=未破且窗口内冲+10%；b=未破且20日收益>0。滚动方案：训1年/验半年/测半年，模型有效期半年连滚（2018H2~2026H2 共 17 个模型）；test 期信号预测 a 丢弃、b/c 保留。信号=analysis_004 全部 8429 次突破，**按当日沪深300成分过滤**（members_asof）→ 4098 只成分内信号。

**result**：
- 标签分布（成分内已判定 3471，test 期）：**a 62.6% / c 25.4% / b 12.0%**
- 17 模型 test：准确率 0.29~0.61（多数类基线 62.6%，**多数模型低于基线**），macroF1 0.21~0.45——分类器弱
- **过滤总效果：保留 1676/3471（48.3%）→ 保留后成功率 36.7% vs 全量 37.4% = -0.7pp，无提升**
- 半年度提升 -16.7pp ~ +13.8pp 正负翻转（噪声）；唯一稳定正值：2020H1 +13.8、2023H2 +4.8、2024H1 +8.9、2026H1 +10.6，但 2019H1 大牛市 -16.7（模型在牛市过度收紧）
- 特征重要度跨模型：**波动率类主导**（Vol20d/Vol45d 反复进 top，M8 中 Vol45d 占 0.854；Vol5d/Vol20d/Vol45d 合计最重要），其次 TurnMean5d、AmtRatio45d、Ret5d、PriceMA20Dev——重要度高≠带来提升
- 附带发现：成分内信号全量成功率 37.4% vs analysis_004 全面板 36.2%——**成分过滤本身 +1.2pp**，比 26 特征模型更有用

**产物**：feature_panel.parquet（668股×全日期 26特征+前向统计大表，预计算可复用）/ model_metrics.csv（17模型全指标+重要度）/ filtered_detail.parquet·csv（每次信号 true_label/pred/valid）/ summary_by_halfyear·year·symbol.csv / result_view.html

**分析（负结果的机理）**：
- 与 analysis_004 结论自洽：信号成败主要由**未来20日市场收益**决定（五分位 19%→62%），该变量在信号时点不可知；26 个价量特征都是**后视**变量，对"这次突破是否兑现"无增量信息
- 树模型学到的近似是"高波动→预测 a"（Vol 特征主导），但高波动同样伴随 c 类（冲+10%），方向互相抵消
- 本分析的正面价值：① 成分过滤 +1.2pp 可直接采纳；② 特征大表 feature_panel.parquet 已沉淀，换模型（如加市场状态特征、改梯度提升/随机森林）零成本重试

**下一步候选**：加入**市场层面特征**（指数动量/市场波动/横截面宽度）重试——analysis_004 已证明个股特征不足；或用 Vol/Turn 简单规则代替树（可解释）；或接受 36~37% 成功率转向离场规则优化（strategy_005 回测）。
