# 分析记录 — analysis_006

## 生成

**main_idea**：v2.7（`plateau_algo_v2.py`）锁死后，用户指定 **v3 新范式：水平阻力带/支撑带系统**（新文件 `shared/plateau_algo_v3.py`，v2.7 不动）。规则：
- 转折点算法同 v2.7（布林带状态机 BB20/1.0）
- 阻力带：转折高点即阻力线，线上下 5% 为带；新转折高点的带与已有带**重叠 → 合并**（合并后线 = 带内全部转折高点**均值**，±5% 为新带，旧带剔除），**递归合并**直到无重叠；**带计数 = 合并的转折高点数**，带记录全部高点
- 支撑带：转折低点对称
- 突破：**收盘价 > 阻力带上边界** → 突破，**突破程度 = 带计数**；跌破对称
- 实现口径：每带只发一次信号；带被合并成新带后重置可再发；带的建立/合并发生在转折点确认日（≤t，无未来）；重叠 = 闭区间相交
- 测试标的：002371（analysis_002 基准股）+ analysis_003 同组四标的，全历史，与 v2.7 信号分布对照

**观察**：
- **信号量 ≈ v2.7 的 2 倍**：水平带长期存续（不像 v2.7 斜线会被断线重置），每带各发一次信号，累计信号更多
- **突破程度高度右偏**：长历史标的高计数占主导（江铜 36 突破中 27 个 degree≥6，新华 20 个）——±5% 水平带会把**跨越数年**同一价区的转折点全部吸进一个带（新华保险最大带计数 32：40~70 元箱体震荡十年的价格记忆）
- **degree 语义**：计数的本质 = "该价区被多少次转折确认"，高 degree = 大级别关卡被破；但它混合了"十年老关口"与"近期密集整理"两种强度完全不同的情形
- 中芯国际（上市短）分布最均匀（3/1/5/5）——样本越短，带越"年轻"
- 活跃带 7~19 个/侧：带群随时间累积，v3 没有带淘汰机制（除合并外）

**分析**：v3 跑通且行为符合规则设计。与 v2.7 相比信号密度翻倍、引入了程度（degree）维度。潜在问题两个：① 带**永不老化**——十年前的转折点永远参与合并，degree 被远古价格记忆稀释/抬升；② 信号密度 2× 在 15bps 成本下的组合换手压力更大（v2.7 已被证明无 alpha，v3 信号量更多但单信号质量未知）。**下一步建议**：仿 analysis_004 做 v3 全市场成功率评估（重点看 degree 分层：高 degree 突破是否比低 degree 更容易成功——这是 v3 相对 v2.7 唯一的新信息维度），以及带时间衰减（如只合并近 N 年转折点）对照。
