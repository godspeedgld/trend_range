## 初建（2026-09-14）：industry/ — 三个热度指标十分位

**main_idea**（用户指定）：三个指标均 = **sw2021 二级行业的日频横截面排名 → 20 日均值**，
信号日 t 取值（0~1 热度分）：
- `HEAT_RET`  = ma(日收益率截面排名, 20)
- `HEAT_TURN` = ma(日换手率截面排名, 20)
- `HEAT_VOL`  = ma(日成交量截面排名, 20)

分析：① 各分十档（等频）看 失败率/成功率/肥尾率/均值/中位 + Spearman 单调性；
② 三指标相关矩阵；③ 分时段 2017-2020 vs 2021-2026；④ t-1 对照；⑤ **行业内中性化诊断**。

**result**（基线：失败率 65.9 / 成功率 33.4 / 肥尾 7.2 / 均值 +1.57 / 中位 −5.12）：

1. **原始口径十档**（档位↔均值 Spearman）：
   - 收益率 **+0.02**——完全无单调性，弱的倒U（D8 +2.21% 最高），**建议砍掉**
   - 换手率 **+0.77**——峰值 D8 均值 +3.31%/肥尾 9.3%（D1 肥尾仅 3.5%）
   - 成交量 **−0.55**——D10 失败率 **78.0%**、均值 **−4.95%**、肥尾 1.8%，清晰禁区
   - 三指标相关极低（RET-TURN 0.17 / RET-VOL 0.14 / **TURN-VOL 0.02**）
   - t-1 与 t 版本几乎一致 → **自反馈可忽略**

2. **⚠ 但原始口径是错的——符号翻转（本次核心发现）**：
   极端档被行业身份证塞满（成交量 D10：证券Ⅱ 21%/电力 19%/房地产开发 17%，仅 21 个行业；
   换手率 D10：半导体 38%/光伏设备 9%）。做**行业内去均值**剥离行业固定效应后：

   | 指标 | 原始 档↔均值 | 行业内 档↔均值 | D1 均值 | D10 均值 |
   |---|---|---|---|---|
   | 收益率 | +0.02 | −0.25 | −1.10% | −0.89% |
   | **换手率** | **+0.77** | **−0.83** ⚠ | +2.47% | −3.48%（失败 75.5） |
   | **成交量** | −0.55 | **−0.94** | +5.56%（失败 58.8） | −2.53%（失败 70.0） |

   → **换手率符号翻转**，典型辛普森悖论：水平上「半导体长期高换手+本身肥尾多」伪装成"高换手好"；
   控制行业后真相 = **任何行业相对自己放量时，突破结果更差**。

3. **结论**：
   - **用户假设被否定**——行业相对自己「变热放量」时突破**更差**，不是更好
   - 与 analysis_014 **个股层面**「巨量禁区」（RV D10 失败率 72.9%）**方向一致，两个层级同向**
   - 收益率热度无效；成交量/换手率剥离行业后是强负向且单调
   - **用原始水平截面排名会得出完全相反的错误结论**——本分析最大教训

## 更新一（2026-09-14）：update1_reverse_decile/ — **反向十分位**（按收益分档反查热度）

**main_idea**（用户）：人工理解「近期总进入收益率排行榜的行业 = 受资金关注，突破后肥尾/失败率应较高」。
父目录是「按**热度**分档 → 看收益」，本更新反过来「按**突破收益** `ret` 分十档 → 看该档的**行业热度**」。
指标 = sw2021 二级行业「近 **10** 日收益率**横截面排名**均值」（用户指定），对照 20 日；口径出
原始 + **行业内中性化**（causal expanding 基线，仅用 t 之前历史，**无父目录诊断版的前视问题**）。

**result**（每档 854 笔，共 8540）：

1. **形状是浅 U 型，不是单调线**（10日·原始，每档热度中位数）：
   D1 **0.581** → 降到 D6 **0.559** → 回升到 D10 **0.571**。**两个极端档都比中段热。**
2. **单调性 Spearman 四变体全负**（−0.18 ~ −0.45）——**但这个检验在这儿是错的工具**：
   它只抓住了 D1→D6 的下坡，漏掉 D6→D10 的上坡。
3. **按 U 型读，用户直觉部分成立**：肥尾档 D10 来自偏热行业，亏损最惨的 D1 来自**最**热行业
   —— 热门行业的突破**结果更极端**（尾部更厚），与策略"高失败 + 右尾彩票"本质一致。
4. **⚠ 幅度很小**：D1↔D6 差 0.022、D1↔D10 差 0.010，而档内 P25–P75 带宽 ≈0.14
   —— 效应仅为档内离散度的 ~1/6。D1↔D6 的 0.022 在 n=854/档下约 5 SE，统计可辨但**经济意义有限**。
5. **U 型跨时段稳定**：2017-2020 与 2021-2026 五分位均两端高中间低。
6. **附带发现（口径重要）**：`ret` 分布双峰——D1–D6 **全是失败单**（100% ret≤0，仅亏多亏少），
   D8–D9 零失败，D10 肥尾率 62.2%。所以"收益十分位"实际在分「亏多少 / 赚多少」，
   **失败率本身是分档的函数**，在本框架下不宜再当被解释变量（与父目录口径的差异点）。

## 更新三（2026-09-14）：update3_ret_minus_turn/ — **价量背离**指标

**main_idea**（用户）：指标 = `ma(收益率横截面排名,10) − ma(换手率横截面排名,10)`。
语义：高值 = **涨了但没放量**（缩量走强）；低值 = **放量滞涨**（拥挤/派发）。
分析流程与更新二完全相同（按 ret 分十档反查 + Spearman + 分时段；对照 20−20 窗口、行业内中性化）。

**result**（每档 854 笔，共 8621）：

1. **形状是倒 U（∩），峰值在中段 D6**：D1 **−0.141** → D6 **+0.121** → D10 **−0.089**。
   **两个极端档都是负值（放量滞涨），中段才是正值（缩量走强）。** Spearman +0.37 同样是错工具
   （只抓住 D1→D6 上坡）。
2. **⚠ 核心发现——成分分解表明该指标没有新信息（原始口径 10 日）**：
   | 档 | 收益率排名均值 | 换手率排名均值 | 差值(=指标) |
   |---|---|---|---|
   | D1 | 0.5805 | 0.7259 | **−0.1408** |
   | D6 | 0.5589 | 0.4301 | **+0.1212** |
   | D10 | 0.5708 | 0.6810 | **−0.0893** |
   收益率成分**几乎平坦**（极差 **0.024**），换手率成分是 **U 型**（极差 **0.296**）
   → **差值 ≈ −换手率**，收益率成分只贡献约 8% 振幅。
   **构造思路对，但行业层面"收益率排名"对突破结果几乎不敏感，差值退化成换手率的反号复制品。**
3. 倒 U **跨时段稳定**：2017-2020（−0.082/+0.014/+0.074/+0.043/−0.054）与
   2021-2026（−0.121/−0.006/+0.139/+0.101/−0.039）两段都两端低中间高。
4. 行业内中性化后峰值由 D6 移到 D5，振幅 0.262 → 0.049（与更新二一致的收缩规律）。
5. 差值为正占比：D6 最高 61.5%、D1 最低 34.8%、D10 37.9%。

**口径提示**：本框架是"按收益分档反查指标"，只说明**不同结果的信号在指标上的构成差异**，
**不等于预测力**。要测预测力须用正向框架（按指标分档 → 看收益/失败率/肥尾率），即父目录初建做法。

## 更新四（2026-09-14）：update4_vol_minus_turn/ — **规模/活跃度错配** + **正向框架**

**main_idea**（用户）：指标 = `ma(成交量横截面排名,10) − ma(换手率横截面排名,10)`。
成交量排名受**行业规模**主导、换手率排名是**相对自身盘子**的活跃度 →
低值 = **小而闹**（小盘活跃），高值 = **大而静**（大盘冷门）。除更新三同款反向框架外，
**新增用户指定的正向框架**（按指标分档 → 看 失败率/成功率/肥尾率/均值）——这才是检验预测力的框架。

**result**（每档 ~862 笔，共 8621）：

1. **★ 正向框架是 R6 系列目前最强的信号**：原始口径 **Spearman 档↔均值 −0.72、档↔失败率 +0.70**；
   最好档 D1（最"小而闹"）均值 **+5.05%**、肥尾率 **10.5%**；最差档 D8 均值 **−2.68%**、肥尾 3.4%；
   **极差 7.73pp 均值**，远超更新一/二/三任何指标。

2. **⚠ 但两个致命问题，证据不支持采用**：
   - **行业内中性化后归零**：−0.72 → **+0.09**，档↔失败率 +0.70 → −0.26 —— **又是行业身份证**
     （低值=小盘活跃，在 2017-2020 恰好对应科技/题材行业，而那是它们的大年）
   - **时段极度不稳定**：原始正向框架 2017-2020 **Spearman −1.0、Q1 +10.91% vs Q5 −0.99%**（近乎完美单调）；
     **2021-2026 完全消失（+0.1，Q1 −0.35% vs Q5 −0.22%）**；行业内口径两段**符号相反**（+1.0 → −0.4）
   - 最合理解释：该指标捕捉的是**"2017-2020 小盘题材风格"这一特定市场状态**，而非行业热度本身

3. **反向框架（A）**：倒 U，峰值档 D5。成分分解（**用均值**——均值可加，中位数不满足故不用；
   表内加"校验列"验证逐行一致 ✓）：成交量成分极差仅 **0.073**（平），换手率成分极差 **0.206**（U 型）
   → 差值仍由换手率主导，与更新三同理。

## 全系列小结（R6 行业维度，更新一~四）

| 指标 | 正向框架（能否预测） | 结论 |
|---|---|---|
| 收益率排名（更新一） | 未测正向 | 反向框架下 U 型深度仅 0.022，**无区分力** |
| 换手率（更新二） | 未测正向 | U 型最深（0.298），中性化后 0.072 |
| 波动率（更新二，新指标=20日滚动std） | 未测正向 | D10−D1 最大（−0.126） |
| 成交量（更新二） | 未测正向 | 最接近单调负向，但**效应仅来自 2017-2020** |
| 价量背离（更新三） | 未测正向 | **≈ −换手率**，无新信息（收益率成分极差仅 0.024） |
| 规模/活跃度错配（更新四） | **−0.72 / +0.70（最强）** | **中性化后归零 + 时段翻符号 → 不采用** |

**贯穿性结论**：① **"热门行业突破更好"的人工假设被四个指标一致否定**，方向相反；
② 原始横截面口径**反复出现"行业身份证"假象**（换手率符号翻转、更新四信号归零）——
**任何行业指标必须做行业内中性化才能下结论**；③ 中性化后效应普遍**减半甚至归零**，
R6 目前没有能进打分体系的稳健指标。
