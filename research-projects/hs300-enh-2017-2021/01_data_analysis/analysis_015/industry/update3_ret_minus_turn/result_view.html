指标：ma(收益率横截面排名,10) − ma(换手率横截面排名,10)（sw2021 二级行业，117 个）。 高值 = 涨了但没放量（缩量走强）；低值 = 放量滞涨（拥挤/派发）。 分析流程与更新二相同：按每笔突破的 ret 分十档（每档 854 笔，共 8540 笔）反查该指标。

形状是倒 U（∩），峰值在中段 D6，不是单调线： D1（最惨，−17.4%）−0.141 → D6（−4.0%）+0.121 → D10（肥尾 +35.2%）−0.089。 两个极端档都是负值（放量滞涨），中段才是正值（缩量走强）。 Spearman 报 +0.37，但同样是错的工具——它只抓住了 D1→D6 的上坡。

其余结论：

  1. 倒 U 跨时段稳定：2017-2020（−0.082 / +0.014 / +0.074 / +0.043 / −0.054）与 2021-2026（−0.121 / −0.006 / +0.139 / +0.101 / −0.039）两段都是两端低中间高。
  2. 行业内中性化后峰值从 D6 移到 D5，振幅由 0.262 降到 0.049——与更新二一致，中性化后幅度大幅收缩。
  3. 差值为正的比例：D6 最高 61.5%，D1 最低 34.8%，D10 37.9%。
  4. 口径提示：本分析是"按收益分档反查指标"（更新二框架），只能说明不同结果的信号在指标上的构成差异， 不等于预测力。若要看该指标**能否预测**突破结果，应做正向框架（按指标分档 → 看收益/失败率/肥尾率）， 即父目录初建的做法。
