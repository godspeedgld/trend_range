## 二、打分机制

**两段式结构**（= regime × 个股 联合）
```
开仓允许度(市场层) = R7 环境分        → 决定今天做不做的权重/软开关
个股质量分(截面层) = Σ wᵢ·fᵢ(R1..R6) → 决定同日候选里选哪几只进坑
```
坑位竞争铁证（供给≫坑、最近优先=零信息）→ **分数只用于排序**，先勿设"低于 X 不开"阈值（重蹈 009 空仓）。

- **方案 A 线性加权**（推荐先做）：符号按证据定死、权重先验（R7 最重→R2/R3→…）；逐条可 A/B 定责。风险=特征边际薄（单特征仅移失败率 5~8pp），合未必强过最近优先 → **先探边再决定**。
- **方案 B 非线性/学习**：逐笔二分类已两次证伪（决策树 AUC≈0.5、LightGBM +2.3pp，右尾主导）；可试 **learning-to-rank/pairwise**（同日 A vs B 谁未来收益高）——仅作 A 跑通后的增强，勿一上来就 ML。
