## main_idea

把已经验收的 **W2 配方**（v4 活带 + 当日成分 + MA200 硬开关 + COMBO 优先排序 + 破线/吊灯止损
+ 无超时 + 10坑×10万 + 15bps + t收盘→t+1开盘 + 无阀）**原样**套到中证500 成分股上，看该配方
的 alpha 是否依赖沪深300 这个池子。

**为什么必须独立重算**：COMBO 的标定是 z(UDVR) − z(log RV)，μ/σ 来自**事件总体的累计统计**。
两个池子的事件分布不同（沪深300 事件 13,852、中证500 事件 28,137），混用会让 z 分数不可比。
故本目录内独立产出面板/事件/COMBO 三件，不复用任何 hs300 中间产物。

## result（权威口径 = trades 直接推算）

**⚠⚠ 本结论经过两次重大更正（2026-09-15），务请看完整过程：**

**更正 1 —— 口径**：首版误用引擎 `equity_curve.csv` 作净值（那是**复利净值路径**，且自述含归因近似）。
按 skill 指标铁律，净值/指标**必须**由 trades 直接推算（`shared/metrics_from_trades.py`，
固定名义 `NAV = 1 + Σ(0.1×单笔收益)`）——这也是 W2 基准 +186.7% 的口径。

**更正 2 —— ATR 缓存 bug（决定性）**：`shared/atr14_precompute.load_atr14()` **优先读全局缓存**
`shared/atr14_panel.parquet`，而那是**沪深300 面板**建的 —— 传中证500 面板进去它照样返回 HS300 的
ATR（668 只），**中证500 独有的 688 只全为 NaN**。后果：
- `build_trades`：18,478 条事件因 ATR 缺失被静默丢弃（28,137 → 只判 9,582，且有偏）
- **W2 策略**：`ATR_PIV` 查不到 → **吊灯止损（离场规则②）与池失效条件②全部静默失效**
修复：本目录自建独立缓存 `atr_csi500.py`（算法与 shared 逐字一致，Wilder ewm α=1/14）。
修复后笔数 166 → **534**。**修复前给出的 −15.7% / −57.0% 错误结论由此而来。**

**结论：W2 配方可以迁移到中证500——两者基本等价。**

1. **收益/风险几乎相同**：中证500 池 +176.4%、Sharpe **0.745**、maxDD −25.6%，
   对比沪深300 池 +186.7%、Sharpe 0.743、maxDD −24.0% —— **Sharpe 几乎完全一致**。
2. **结构略有不同但同样成立**：中证500 胜率更低（30.5% vs 36.8%）、失败率更高（69.5% vs 63.2%），
   但**盈亏比更高（4.05 vs 3.51）**——「高失败 + 罕见巨大右尾」的彩票结构**依然存在**
   （肥尾率 8.2% vs 7.9%）。**中盘池的右尾更厚、但兑现率更低**，两者相互抵消。
3. **MA200 闸门必须用沪深300**：换成中证500 自身年线后掉到 +79.4%（Sharpe 0.332、maxDD −40.9%）。
   中证500 的 MA200 开门日只有 1,408 天（沪深300 为 2,755 天），过滤更严且时点偏离。
   **市场 regime 代理应固定用沪深300，不要换成被交易指数。**
4. **纯 v4 信号层对照**（`build_trades.py`，全 degree 无过滤）：中证500 27,936 笔、
   期望 +0.84%、失败率 68.3%、肥尾 7.4%；沪深300 11,100 笔、+1.57%、66.4%、7.2%。
   信号层中证500 略逊，但组合层追平 —— 说明**组合层的排序/闸门在中盘池上同样有效**。

### 执行层：资金约束已排除，但仍有 10.5% 不匹配

- **云端 3M 资金版**（用户 09-15 重跑）：建仓 <5万的笔数 **25 → 0**，资金约束解除
- 买入口匹配 538/601 = **89.5%**（W2 沪深300 移植时为 98.7%）
- **本地独有 21 笔均值 +11.39%**（占总收益 **24.7%**）；云端独有 23 笔均值仅 +1.75%
- **这种不对称不是随机的**

### 根因定位：池失效规则②（吊灯）判定分歧 → 路径分叉

```
国轩高科 信号 2020-05-29，COMBO = 4.72（当日全场最高）
  06-05  close 126.45  <  peak−4×ATR 129.60   →  本地判定【池失效】
  06-08  close 128.89  <  peak−4×ATR 129.88   →  本地仍在【池外】
  本地：买不到国轩高科 → 改买王府井 → +133.5%
  云端：未清出          → 06-08 买入国轩高科
```

同一批交易还有**浮点刀锋**：国轩高科 06-01 的"涨超10%出池"阈值
`close − close_sig×1.10 = −2.84e-14`，差 2.8e-14 未触发。
**此类边界只要两边实现差一个 epsilon，结果即分叉。**

### 结论（**修正用户问题：中证500 是否值得用**）

| 口径 | 沪深300 池 W2 | 中证500 池 W2 |
|---|---|---|
| 本地（理想化） | +186.7% | +176.4% |
| **云端（可执行）** | **≈ +173%**（净，1M 口径） | **≈ +39%**（净，1M 口径；毛 58.5%） |

**可执行口径下中证500 明显不如沪深300（净 +39% vs +173%）。**
先前"两者等价"的结论**只在理想化口径成立**——本地 597 笔中 21 笔独有大赢家（王府井 +133.5%、
卫星石化 +85.4%）贡献总收益 23%，而这几笔**对执行细节最敏感**（坑位竞争 + 池失效边界）。
沪深300 的 edge 分布更平均，漏一笔不致命；中证500 漏一笔就掉 13pp。

**→ 决策：中证500 在 W2 规则下不采用。**（可选替代路线：超跌反弹 / 小盘轮动，而非追突破）

   引擎 `equity_curve.csv` 是复利路径且自带归因近似，本例两者差近 100pp。
