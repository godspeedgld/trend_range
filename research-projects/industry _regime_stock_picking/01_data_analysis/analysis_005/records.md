**main_idea**：四步计划第 3 步（承接 analysis_003 标尺、analysis_004 随机对照）。
把 QuantSkills 库的**全部 512 个因子**（`v_factor_1w`，见 memory `factor-weekly-warehouse`）在
**与 analysis_003 完全相同的条件**下逐个评测，找出比基线四因子更好的，再对入选者做**正交检验**。

口径（不改 analysis_003）：
- 池 = 每周当周 top3 行业内候选股（`analysis_003.load_pool`）：**154,548 行 / 494 个信号日 / 313 只·周**
- 收益 = 池内 `ret_ww`（exec_open(t) → exec_open 下一信号日）
- 指标 = 逐周截面 Spearman 方向化 IC / ICIR / t / \|IC\|≥0.02 占比 / 五分位单调性 ρ / 累计 IC 线性拟合 R²
- **方向**：每因子取 \|IC\| 更强的方向（表内 `方向` 列）。★ **样本内选择**，见「诚实标注」
- **入选门槛**：六项**逐项与最强基线因子比**（严格大于），**至少过 3 项**
- **正交**：与基线四因子（方向化）+ 复合分、及其他入选者的池内逐周截面 Spearman 均值 \|ρ\| < 0.7 才保留

**结论**：

1. **`breakdown`（下轨跌破）是唯一系统性优于基线的信号族**——5/7/10 周 × smooth/compress/confirm_volume

## 口径注记（修复记录）

1. **单调性 ρ 必须用 Pearson**（组号 vs 组均收益），与 analysis_003 一致 —— 用 Spearman 会在严格单调时
   恒等于 1.0，把这一项变成死门槛。
2. **分箱要"掩码子集内现算秩"** —— 若用整列秩 ÷ 掩码内 n，比值 >1，最后一组会吞掉溢出行、ρ 假性 = 1.0。
3. **方向要真的按 IC 均值符号选**（首版把库因子一律写死 +1，导致负 IC 因子方向标错、累计 IC 曲线朝下）。
4. **IC 实现**与 `pandas corr(method='spearman')` 在 5 个随机因子上断言逐值一致；
   `reversal_5w_z` 单因子冒烟 IC +0.041344 / t 5.597，与 temp 里的独立测试（+0.0413 / +5.60）吻合。
