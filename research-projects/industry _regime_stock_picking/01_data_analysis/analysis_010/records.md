# analysis_010 — A2 臂：随机行业对照（block bootstrap，20 种子）——三层贡献四臂收口

## 生成（2026-10-15）

**main_idea**：用户问「基线四因子策略的**行业贡献 / 因子选股贡献 / 空仓贡献**能否分别检验」。
四臂消融设计（每层一个对照臂，其余保持真实）；A1（去空仓，strategy_006）与 A3（随机选股，
analysis_004）已测，本分析补 **A2 随机行业臂**（用户裁定只做 A2）。

**A2 设计要点（块自助法）**：`shared/build_random_industry_targets.py`（新增，只 import 冻结件）——
只在 `weekly_plan` **真实 top3 集合发生变化的周**（314 个切换块）从当周面板行业里随机抽 3 个
持有到下一块；选股/缓冲/权重/成本/引擎全同基线（真实四因子恒反转）。
★ **exposure（稳定性空仓）日程与基线逐周一致**（构建后 assert，20 种子全部 mismatch=0）——
随机行业只在"真实已切换"时点重抽，否则空仓过滤会退化成永空仓，对照失效。
★ 踩坑：随机块偶发与上一块抽中相同 3 行业（p≈1/4495，20 种子 × 314 块实测撞中 1 次）→
真实切换了、随机没切换，exposure 多一周满仓 → **拒绝采样**强制新块 ≠ 旧块。

**引擎**：`run_weight_backtest` 进程内；指标全 trades 口径、共同区间 ≥2017-05-12（004/007 同款）。
种子 1001~1020。

## 诚实标注

1. **条件贡献不可加**：三条差值都定义在"其余层保持真实"上，1.23+1.40+1.45=4.08 > 3.60−骨架底，
   层间有交互与重叠（例：空仓过滤的存在放大了行业信息的价值——A1 臂里行业层贡献会变小）。
   各臂全值才是事实，差值只作量级排序。
2. 20 种子下「100 分位」≈ 1/20 显著性边缘（与 analysis_004/007 同款标注；p≈0.05 量级）。
3. A2 随机行业从当周面板行业中均匀抽（不按 regime 分层）——若动量/反转行业的票池结构差异
   本身有信息，A2 会略微低估行业层贡献（更严零假设方向，结论偏保守）。
4. A1（strategy_006）为全窗口 2361 期，但其首个有仓日与基线共同区间起点相同（2017-05-12），
   四臂数值可直接横比。
