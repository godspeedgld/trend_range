## 1. 研报背景

系列一（4-21）论证了拐点三大因素（其中公积金利率/核心城市房价/人民币汇率为市场忽略的三大因素，见 `real_estate_turning_three_factors_caitong_20260421` 卡）；本篇回答下一个问题：**若反转发生，买什么**。通篇是"修复空间测算"：用三种估值方法（PB 相对法 / 静态 RNAV / 动态 RNAV）给 10 家重点房企排序。

### 1.1 观察现象

**① 历史四轮地产周期的 PB 复盘**（原文口径，未复现验证）：

| 周期 | 起点（政策） | PB 底→顶 | 底部最大反弹 | 修复到前高 |
|---|---|---|---|---|
| 2008-09 | 降准降息+四万亿 | 1.60x → 4.70x | **194%** | 63% |
| 2012-13 | 降准+满足首套信贷 | 1.68x → 2.24x | 33% | 82% |
| 2014-16 | 930 新政+棚改货币化 | 1.46x → 4.09x | **180%** | **100%**（破前高） |
| 2018-19 | 降准+地方微松 | 1.13x → 1.70x | 50% | 76% |
| **四轮平均** | | | **114%** | **80%** |

规律：**全国性大放松（08/14）反弹 180%+，地方性微调（12/18）只有 33-50%**——政策力度决定反弹量级。

**② 2021 年至今 5 轮"政策博弈"短行情**（金委会维稳 / 三支箭 / 三大工程 / 收储 / 924）：时间短、斜率高、"买预期卖现实"，估值中枢不稳定——**房价未反转前，地产股只是政策博弈筹码**。

**③ 长期约束**：城镇化率/人口/人均居住面积/居民杠杆率已非 08/14 之环境；净利率、杠杆率、周转率三降压制 ROE——**稳态后房企 ROE 将落在"金融业与传统制造业之间"，PB 中枢回不到历史高位**（图5：五年/十年中枢均在持续下移）。

## 2. 核心观点

### 观点 2.1：PB 相对估值——本轮修复空间平均 117%~191%

| 要素 | 内容（忠实提取） |
|---|---|
| **观点内容** | 假设本轮 PB 修复到五年/十年最高值的 70%（取四轮"修复到前高 80%"打七折的保守口径），十家房企平均修复空间 117%（五年）/ 191%（十年） |
| **逻辑依据** | 924 后政策力度（降首付/降利率/基本解除限购）不低于 08/14 两轮全国性大放松 → 反弹量级可类比；但行业天花板已现 → 打七折并用五年/十年中枢而非历史前高 |
| **事实依据** | 四轮周期复盘（见 1.1①）；2021 以来五轮政策博弈行情 |
| **数据依据** | 十家 PB 分位数：五年平均 29%、十年平均 20%（截至 2026-05-29，后50%除金茂）。五年修复空间前列：龙湖 563%/**建发国际 132%/保利 177%/越秀 93%**；十年前列：建发国际 317%/保利 307%/招商蛇口 172%。**作者主动剔除龙湖**：其高 PB 基于商业+住宅双轮成长逻辑，近年拿地大收缩、定位已从开发商转向运营商，历史 PB 分位失真（原文口径，未复现验证） |
| **观察指标及说明** | 个股 PB 分位数（vs 五年/十年区间）——分位越低 + 反转确认 → 修复空间兑现；PB 分位快速爬升 = 空间收窄 |

**观点解释**（分析者解读）：PB 相对法的本质是"均值回归假设"——历史周期里 PB 底部反弹 114% 的机制是**盈利预期与风险溢价同时修复**。此法对"周期回归"的定价最快，但有两个隐性风险：① 它假设分位区间本身平稳，而作者自己也承认中枢在下移（用"70% 折扣"部分处理了）；② 高分位≠贵、低分位≠便宜——龙湖一例说明**商业模式变了的历史分位没有可比性**，这是所有分位数方法的通病。证伪条件：政策力度证明只是"地方微调级"（对照 12/18 轮，反弹仅 33-50%）。

### 观点 2.2：静态 RNAV——市值平均折让 49%

| 要素 | 内容（忠实提取） |
|---|---|
| **观点内容** | `RNAV = 归母净资产账面 + 开发物业重估 + 投资物业重估`；当前十家市值较 RNAV 普遍折让 25%~65%、平均 **49%**，平均修复空间 105% |
| **逻辑依据** | NAV 理论上=全项目现金流折现加总，但逐项目测算数据不可得、误差累积会成"精准的错误" → **自上而下按大类口径**简化；忽略折现（结转节奏不可预测） |
| **事实依据** | 开发物业四分法（下）；投资物业 NOI/cap rate 重估 |
| **数据依据** | **开发物业重估**（销售底层资产四分法）：已售未结=利润锁定能贡献利润；未售期房=新项目（毛利率 15-20%，归母净利率中高个位数）多数盈利、2021 前老项目亏损；未售现房=大概率亏损（减值充分则不亏）；**未售土地=保守记零价值**。招商蛇口前海土地入账偏低，调规后或增值超百亿。**投资物业重估**（NOI/cap rate 法：2026E 租管收入 × NOI 率 ÷ cap rate 5.5%-8.0%）：华润置地**增值 +502 亿**（购物中心内生增长强）、中海外**折价 -1094 亿**（写字楼压力+账面偏高）。折让最深的：越秀 -64%、绿城 -62%、中海外/龙湖/建发国际 -52~53%（原文口径，未复现验证） |
| **观察指标及说明** | 市值/RNAV 比值——折让深度即安全边际；RNAV 本身随减值计提/租金变化重算 |

**观点解释**（分析者解读）：RNAV 是把"清算价值"当底——**它不预测反转，只回答"如果反转，价格离地面多远"**。方法学上最值得借鉴的是"开发物业四分法"：把不可观测的土储价值拆成（已售未结/期房/现房/土地）四个可分别假设的桶，且**未售土地记零、现房默认亏损**——保守到近乎苛刻，这正是它在熊市里有说服力的原因。风险：所有"重估"都依赖分析师假设（NOI 率、cap rate、权益比例），中海外 -1094 亿的单点调整足以改变排序——输入的主观性与输出的精确感不匹配。证伪条件：房价继续下行，则"未售期房多数盈利"的前提瓦解，RNAV 整体下修。

### 观点 2.3：动态 RNAV——房价温和复苏情形下，一线货值占比高者弹性最大

| 要素 | 内容（忠实提取） |
|---|---|
| **观点内容** | 假设房价温和复苏（核心城市领涨），重估未售期房货值：三情形下市值较动态 RNAV 平均折让仍 50%、平均修复空间 **>110%**；一线占比高且新货多者（越秀、中海外、招商蛇口）受益最大 |
| **逻辑依据** | 成本费用刚性 → 房价涨幅全部落入货值与利润率；只增厚在建期房，土地/现房老货不受益；各能级占比与全部未售货值占比近似相同（数据可得性假设） |
| **事实依据** | 前端积极信号：公积金新政后实际贷款利率逼近租金收益率；核心城市淡季不淡、低总价房源企稳；人民币升值打开政策空间（引系列一） |
| **数据依据** | 三情形房价涨幅假设：一线 +8%/+5%/+3%、二线 +5%/+3%/+1%、三四线 +3%/+1%/0%；`加权涨幅 = Σ(能级货值占比 × 能级涨幅)`。一线货值占比最高：越秀、中海外、招商蛇口。动态较静态弹性（乐观）：越秀 23%/建发国际 12%/保利 13%；市值较动态 RNAV 折让最深（乐观）：越秀 -71%/绿城 -65%/中海外 -56%（原文口径，未复现验证） |
| **观察指标及说明** | 70 城房价环比（分能级）——一线先转正 = 情形向乐观迁移；各房企土储能级结构（年报/业绩会披露） |

**观点解释**（分析者解读）：动态 RNAV = 静态 RNAV × 一个"房价 Beta"（由土储能级结构决定）。它把选股从"谁折得深"推进到"**谁对房价反转的弹性大**"——本质是给每家房企算了一个对一线房价的杠杆。注意弹性的不对称性：悲观情形下越秀仍有 200% 修复空间，说明排序主要由**折让深度**主导、房价情形只调边际。证伪条件：房价复苏从三四线开始（历史上从未发生过，但假设"核心城市领涨"本身是外推）。

### 观点 2.4：选股胜负手——土储结构与质量决定修复次序

| 要素 | 内容（忠实提取） |
|---|---|
| **观点内容** | 无论 PB 还是 NAV 法，本质都是对投资物业+开发物业质量的定价；反转后**胜率赔率的胜负手 = 开发物业能贡献多少利润** |
| **逻辑依据** | 土储结构质量直接决定销售与利润；**近年拿地多 + 布局高能级 + 历史包袱轻 + 减值计提充分**的房企率先修复业绩与估值（新货高毛利稀释老货拖累） |
| **事实依据** | 新项目销售毛利率 15-20%（vs 2021 前老项目持续亏损）；华润/中海外开发物业重估贡献 +373/+357 亿 vs 保利 **-463 亿**（老货拖累） |
| **数据依据** | 见表2/3/4/6 汇总（原文口径，未复现验证） |
| **观察指标及说明** | 拿地金额/销售金额比（扩张意图）、新增土储城市能级、累计减值拨备/归母净资产（包袱出清度） |

**观点解释**（分析者解读）：这是三种估值方法的收束点——PB 分位回答"便宜吗"、RNAV 折让回答"值多少"、**土储质量回答"谁先涨"**。翻译成因子语言：估值因子（PB 分位）决定空间，质量因子（土储结构）决定次序与确定性——典型的"深度价值 + 质量排序"组合框架。它与系列一"四低"框架的差别正是从"无人问津"（低持仓/低拥挤）到"资产折价"（RNAV 折让）的重心迁移。

## 3. 投资建议

### 建议 3.1：推荐 越秀地产、绿城中国、建发国际集团、中国海外发展、龙湖集团

| 要素 | 内容（忠实提取） |
|---|---|
| **建议内容** | 综合报表质量、经营情况、绝对与相对估值后推荐上述五家（前三权重信号最强：越秀/绿城/建发国际在"动态弹性大 + 折让深"双榜均为前三） |
| **逻辑依据** | 房价拐点渐近预期下，胜负手是开发物业利润贡献 → 拿地多、能级高、包袱轻、减值充分者先修复（观点 2.4） |
| **事实依据** | 三种方法排序汇总（表7）：PB 修复空间前列（建发国际/保利/越秀）、RNAV 折让前列（越秀/绿城/中海外）、动态弹性前列（越秀/建发国际/保利） |
| **数据依据** | 五年 PB 修复空间：保利 177%/越秀 93%/建发国际 132%；静态 RNAV 折让：越秀 -64%/绿城 -62%/中海外 -53%；动态弹性（乐观）：越秀 23%（截至 2026-05-29，原文口径，未复现验证） |
| **观察指标及含义说明** | 70 城房价环比转正（情形确认）；个股 PB 分位爬升速度（空间兑现）；房企月度销售同比（业绩先导）——若销售持续负增长而股价先涨 = 又一轮政策博弈而非基本面反转 |

**建议解释**（分析者解读）：赚的是**估值修复的钱**（市值→RNAV 的 50% 折让收敛），催化剂是房价拐点确认。与系列一（20260130）的推荐对照是**本篇最有信息量的地方**：A股滨江/新城/招商蛇口 → 越秀/绿城/建发国际/中海外/龙湖，**标的几乎全换、且换向港股**——四个月后选择标准从"四低筹码论"（没人要+不拥挤）迁移到"折价深度论"（RNAV 折让+房价弹性），说明作者认为底部第一波（筹码修复）已走完，下一波要靠资产折价收敛驱动。这暗含一个可检验命题：**第一篇的基本面标的（滨江 ROE 5.13% 最高）在本篇被 PB 分位 49%/修复空间仅 22% 剔出推荐——不便宜了**。风险：RNAV 全链条建立在分析师假设上（cap rate/NOI/货值结构），若房价二次探底，"未售期房多数盈利"前提失效，折让数字失去意义；龙湖的运营转型逻辑被重新纳入推荐（与 PB 法剔除它形成方法间张力，作者靠 NAV 法拉回）。
