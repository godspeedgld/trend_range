## 1. 研报背景

地产经历多年筑底，市场核心分歧在于**基本面拐点是否临近**。作者为财通地产团队（本文为其"拐点"系列的前奏篇：目录中可见后续系列二 20260531、系列三 20260625、研究四 20260915），立场鲜明：拐点渐行渐近，当前虽略偏左侧，但**值得逢低建立底仓**。论证分三层：现实（基本面已经不弱）→ 预期（政策与利率条件仍在改善）→ 仓位（股价/估值/持仓/拥挤度四低，赔率好）。

### 1.1 观察现象

- 2025 年政策普遍未加码背景下，二手房市场依靠自身韧性维持量能（作者视为"内生需求旺盛、比政策脉冲更健康"的证据）；
- 过去几轮政策效果不佳的归因：**少数多方弱于多数空方**——政策落地后持有者视为出货机会、挂牌量持续上升，需求释放不及抛盘供给，价格再度下行（原文逻辑，无量化统计）；
- 历史经验（中国香港本轮）：**地产股股价拐点领先房价拐点 2-3 个月**，2025 年 1 月/4 月至今港地产指数涨幅分别 48%/53%（原文口径）。

## 2. 核心观点

> 原文三大论点（现实不弱 / 预期增强 / 逢低布局），其中前两者各含三条独立证据链，按模板拆分为 7 个要点。

### 观点 2.1：现实不弱·量——一线城市二手房成交活跃，内生需求有支撑

| 要素 | 内容（忠实提取） |
|---|---|
| **观点内容** | 无政策加码背景下 2026 年 1 月二手房仍成交活跃，一线及三四线已超 2025 年同期高基数 |
| **逻辑依据** | 成交量靠自身韧性维持 → 内生需求旺盛、比"政策推动积压需求集中释放"更健康持续；量能释放是消化库存→供需均衡→价格获支撑的必要环节 |
| **事实依据** | 2025 年政策普遍未加码；春节假期靠后 |
| **数据依据** | 截至 2026-01-28：22 城/一线/二线/三四线二手房成交面积 997/350/424/223 万方；冰山活跃度：1 月一线、新一线与 2020 年至今平均活跃度相当、普遍高于近五年同期（原文口径，未复现验证） |
| **观察指标及说明** | 22 城及分线二手房成交面积（周频，iFinD）；冰山活跃度指数（前端指标）——持续高于同期 = 验证；骤降 = 证伪 |

**观点解释**（分析者解读）：二手房成交量是地产周期最领先的量能指标（先于新房、远先于土地）。作者强调"无政策加码下的放量"，是想剔除政策脉冲的混杂、识别内生需求——这一识别思路本身比数字更重要。失效条件：春节后"小阳春"成色不足（原文自己点名的验证时点）。

### 观点 2.2：现实不弱·供给——一二线挂牌量高位回落，供需走向平衡

| 要素 | 内容（忠实提取） |
|---|---|
| **观点内容** | 一二线城市二手房挂牌量从高位回落，供给压力边际缓解 |
| **逻辑依据** | 挂牌量下降 = 成交消化 + 卖方主动撤牌（部分房源已击穿卖方心理价位，除非现金流压力否则转为收租资产）→ 新增抛盘减少 + 低价房源消化完后，市场可能在新的价格平台上重新平衡 |
| **事实依据** | 上海、武汉、合肥挂牌量下降明显；上海月均成交近 1.8 万套 |
| **数据依据** | 截至 2025 年末：一线挂牌 45.7 万套（较 2025-10 高位 **-6.8%**）；二线 487.0 万套（较 2025-11 高位 **-1.0%**）；上海/武汉/合肥 9.9/16.8/22.1 万套，较自身高点 -21.5%/-16.0%/-27.9%；上海去化周期 5.6 个月（原文口径，未复现验证） |
| **观察指标及说明** | 中指研究院分城市挂牌量（月频）；去化周期 = 挂牌量 ÷ 过去 6 个月平均成交——持续回落 = 验证 |

**观点解释**（分析者解读）：这是对"政策为何总是失效"（供给端抛盘压制）的针对性观察——挂牌量是二手房市场的"隐性供给库存"，其拐点往往先于价格拐点。注意二线仅 -1.0%，幅度远弱于一线样本城市，作者的证据集中在少数城市，外推需谨慎。失效条件：政策利好再起时挂牌量重新上升（重回"利好=出货"模式）。

### 观点 2.3：现实不弱·价——环比跌幅收窄，上海杭州冰山指数转正

| 要素 | 内容（忠实提取） |
|---|---|
| **观点内容** | 2025-12 以来各线城市价格周环比降幅收窄，2026 年 1 月第三周起上海、杭州转正 |
| **逻辑依据** | 沪杭基本面更扎实、供需更健康，或有望领先全国企稳 |
| **事实依据** | — |
| **数据依据** | 一线周环比由 2025-12 初 -0.4% 收窄至上周（2026.1.19-1.25）+0.0%（2025 年 2 月以来首次止跌）；新一线 -0.5%→-0.1%；二线 -0.4%→-0.2%；上海连续两周 +0.0%/+0.2%，杭州 +0.1%/+0.3%（环比经 MA4 平滑；原文口径，未复现验证） |
| **观察指标及说明** | 冰山指数周环比（分城市）——降幅收窄→止跌→转正的阶梯；持续性是关键 |

**观点解释**（分析者解读）：价格是供需的结果确认，放在"现实不弱"的最后一块恰好构成 量→供给→价 的完整证据链。两个月的环比收窄样本很短，且 MA4 平滑会滞后；单城转正的统计意义有限。失效条件：春节后环比重新走阔。

### 观点 2.4：预期增强·政策——北京新政验证有效，沪深有望加码

| 要素 | 内容（忠实提取） |
|---|---|
| **观点内容** | 北京新政后量升价稳，作为调控最严城市是风向标；市场期待沪深进一步放开限购，与不弱基本面共振 |
| **逻辑依据** | 北京 = 一线城市风向标；官方定调（房地产"金融资产属性"、传统产业"不能喜新厌旧"）指示政策空间 |
| **事实依据** | 北京 2025-12 出台楼市新政；《求是》2026-01-02《改善和稳定房地产市场预期》；新华网 2026-01-28《产业发展，总书记强调不能喜新厌旧》 |
| **数据依据** | 截至 2026-01-28 北京二手成交 13044 套（日均 466 套，1 月有望约 14500 套）创近五年最高；北京冰山指数周环比收窄至 0.0%（2025 年 2 月以来首次止跌）（原文口径，未复现验证） |
| **观察指标及说明** | 北京周成交套数与冰山环比；沪深限购政策公告——落地 = 兑现催化剂 |

**观点解释**（分析者解读）：典型的"试点→推广"政策推理：北京作为最严调控城市放松后未失控、反而量升价稳，降低了决策层对进一步放开的顾虑。这条观点的兑现依赖政策出台，属**事件驱动型预期**，时点不可测——这也是作者承认"略偏左侧"的主因。失效条件：政策迟迟不落地或力度低于预期（风险提示第一条）。

### 观点 2.5：预期增强·利率——租金回报率与贷款利率利差收敛至 67bp，降息+贴息是可行路径

| 要素 | 内容（忠实提取） |
|---|---|
| **观点内容** | 楼市企稳的必要条件之一是"租金回报率 = 贷款利率"；当前利差已收敛至 67bp，2026 年政策路径可能是降息 + 贴息 |
| **逻辑依据** | 资产定价锚：持有房产的机会成本（贷款利率）低于租金收益率时，买房出租变为正现金流资产，需求获得内生支撑 |
| **事实依据** | 2025 年五年期 LPR 仅 2025-05 降一次 10bp 至 3.5% |
| **数据依据** | 截至 2025-12 末：百城/一线/二线/三四线租金回报率 2.4%/1.8%/2.7%/3.0%；2025Q4 新发商贷 3.06%、五年以上公积金 2.6%（综合购房成本 2.8%-3.0%）；百城租金回报率-商贷利差 **67bp**、-公积金 **21bp**（历史序列 178bp→83bp→67bp）；贴息 46bp 即商贷与公积金持平、低于二三四线名义租金回报率（原文口径，未复现验证） |
| **观察指标及说明** | 利差 = 新发商贷利率 − 百城租金回报率——收敛至 0 = 条件达成；LPR/公积金利率调整公告 = 催化剂 |

**观点解释**（分析者解读）：全篇最"硬"的一条——把政策预期锚在一个**可计算的价格条件**上（利差），而不是空喊"政策加码"。这正是资产收益率 vs 融资成本的 Carry 框架：分城市看二三四线名义回报率 2.7-3.0% 已高于商贷 3.06% 附近，**低线城市的企稳条件其实先于一线成熟**（一线 1.8% 距离尚远，靠的是升值预期/稀缺性）。失效条件：租金随房价补跌导致回报率回落，利差被动走阔。

### 观点 2.6：预期增强·宏观——走出较弱通胀，扭转房价预期（反身性）

| 要素 | 内容（忠实提取） |
|---|---|
| **观点内容** | 十五五开局年扩大内需，若走出较弱通胀，实际利率下行 + 租金企稳，有望扭转房价下跌预期 |
| **逻辑依据** | 房地产具备金融资产属性与**反身性**（预期自我实现）：通胀回升 → 实际利率向下、房贷实际利率下降、租金止跌 → 回报率上升 → 下跌预期扭转 → 打破价格螺旋下降的恶性循环 |
| **事实依据** | 2025 中央经济工作会议与十五五规划建议的表述；潜在抓手：更宽松货币、更积极财政、反内卷拉 PPI、投资于物与人结合 |
| **数据依据** | 2025 年 8-12 月 PPI 同比降幅连续 5 个月收敛；2025 年 10-12 月 CPI 同比连续 3 个月为正（原文口径，未复现验证） |
| **观察指标及说明** | CPI/PPI 同比（月频）+ 央行城镇储户"预期未来房价上涨占比"——通胀回升 + 预期占比回升 = 兑现 |

**观点解释**（分析者解读）：这条把地产放进宏观利率框架（实际利率是房价的贴现率）。反身性的提法意味着作者承认预期是快变量——**这也提示股价可能抢跑基本面很远**（香港经验里股价领先房价 2-3 个月正是这种抢跑的体现）。失效条件：通胀回升被证伪（PPI 降幅重新走阔）。

### 观点 2.7：逢低布局——股价、估值、持仓、拥挤度四低，赔率占优

| 要素 | 内容（忠实提取） |
|---|---|
| **观点内容** | 地产股股价涨幅落后、PB 破净、公募持仓创新低、交易拥挤度低——筹码结构好，向上阻力小 |
| **逻辑依据** | 低持仓 + 低拥挤度 = 谁都没拿够货，增量资金入场时弹性大（赔率与胜率明显增加） |
| **事实依据** | 924 行情（2024-09-24）至今 |
| **数据依据** | A 股地产累计涨幅 32.1%（31 个申万一级中**第 24 位**，最大涨幅 51.9%）；港股地产 39.0%（11 个 Wind 港股行业中第 9）；申万地产 PB **0.88x**、Wind 香港地产 PB **0.5x**（2026-01-29，均破净、处近五年均值附近）；2025Q4 主动偏股+灵活配置基金地产持仓占比 **0.27%**（历史最低，环比 -0.31pct）、超配 **-0.61%**；1 月 A 股地产拥挤度 ≤1.5%（低位），港股 1-29 升至 7%（阶段高点但仍低区间）；乖离率 MA5：A 股 ±1% 内、港股 0-2%（原文口径，未复现验证） |
| **观察指标及说明** | 行业 PB 分位 / 公募持仓占比（季频）/ 成交额占比即拥挤度 / 乖离率 MA5——四项从低位回升 = 兑现中；拥挤度或乖离率冲极端高位 = 止盈信号 |

**观点解释**（分析者解读）：前三层是"胜率"论证（基本面+政策+宏观），这一层是"赔率"论证——典型的左侧买入 checklist：**涨幅落后 + 破净 + 无人持仓 + 不拥挤**。逻辑上等于"下行空间有限、上行弹性大"，但四低本身不构成催化，需要观点 2.4/2.5 的政策与利率条件兑现来点火。风险：四低状态可以维持很久（价值陷阱），港股拥挤度已在爬升（7%）是需跟踪的边际变化。

## 3. 投资建议

### 建议 3.1：拐点机会值得重仓，当前位置略偏左侧，先建底仓

| 要素 | 内容（忠实提取） |
|---|---|
| **建议内容** | 明确拐点机会值得重仓；即使位置略偏左侧，先建立底仓亦是不错的选择 |
| **逻辑依据** | 基本面拐点渐行渐近 + 若政策组合拳有序有力出台，地产股有望率先迎来拐点；中国香港经验：**股价拐点领先房价拐点 2-3 个月**，等右侧确认房价再买股价已经晚了 |
| **事实依据** | 中国香港楼市 2025-03 中旬价格拐点确立后，港地产股自 2025-01/2025-04 至今涨幅 48%/53%，修复持续且力度大 |
| **数据依据** | 见观点 2.1-2.7 汇总（原文口径，未复现验证） |
| **观察指标及含义说明** | 综合观察：量（2.1）/ 挂牌（2.2）/ 价（2.3）/ 政策（2.4）/ 利差（2.5）——多指标共振时加仓；证伪信号 = 政策不及预期、宽松无效、房企违约（原文风险提示三条） |

**建议解释**（分析者解读）：这是全篇的仓位结论，赚的是**行业拐点 + 估值修复**的钱（PB 0.5-0.88x → 均值回归），不是景气延续的钱。与观点的自洽性好：胜率（2.1-2.6）× 赔率（2.7）的乘积逻辑。最大风险恰在"左侧"二字——底仓若遇房企违约（风险提示第三条）会有第二波下杀；香港"领先 2-3 个月"样本仅一轮，作为择时锚的外推性弱。
