## 1. 研报背景

系列一回答"为什么拐点将至"（三大因素）、系列二回答"反转买什么"（三种估值排序），本篇补最后一块：**何时买、怎么识别节奏**。方法 = **香港映射法**：香港楼市 2025-03 已完成一轮完整筑底复苏（港资房企走出逾一年独立行情），把其拐点前后的股价表现切成阶段复盘，再对标内地当前所处位置。触发背景：2026-04-09~05-12 内房股冲高 +26% 后回调，市场困惑"这是脉冲还是起点"。

### 1.1 观察现象（香港本轮周期事实链，原文口径）

- **量先于价两年**：香港新房成交量 2022 年见底（1.03 万套，2019 峰值 2.11 万），二手房 2023 年见底（3.23 万套，2021 峰值 5.66 万）；2025 年新房 2.05 万套（近翻倍）、二手 4.23 万套（+31.1%）
- **价**：私人住宅售价指数 2021-09 见顶 → 2025-03 筑底（回撤 **28.3%**）→ 2025-12 累计 +5.2%、2026-04 累计 +11.1%
- **利率条件**：2025-05-07 起 1M HIBOR 由 3.66% 骤降（次日 2.09%），H 按利率 5-13 跌破 3% 并维持至 8 月；**A 类住宅租金回报率 2024-12 起高于按揭利率（"供平过租"）**
- **情绪领先**：中原经纪人指数 2025-01-27 见底 43.8（好淡分界 45），**先于房价指数筑底约 6 周**

## 2. 核心观点

### 观点 2.1：港资股价"左侧抢跑"——领先基本面拐点约 1 个月

| 要素 | 内容（忠实提取） |
|---|---|
| **观点内容** | 行业拐点远端股价只是大盘 Beta；**临近拐点前约 1 个月股价率先启动趋势性上涨** |
| **逻辑依据** | 领先指标（经纪人指数）改善 → 市场提前交易"房价拐点"预期（NAV 折价修复逻辑），不等基本面数据确认 |
| **事实依据** | 中原经纪人指数 2025-01-27 见底 → 主要港资房企 2025-02-11 启动（经纪人指数后 9 个交易日、**领先中原城市领先指数筑底 2025-03-16 前 24 个交易日**）；3 月下旬特朗普关税扰动回调，剔除后绝对收益胜率占优 |
| **数据依据** | 远端（2024/8-12）：区间累计仅 **4%**、高波动、六阶段全部跟随恒指（美联储降息预期↔回吐↔924 政策↔大选强美元↔降息预期收敛+新世界违约恐慌）；前夕（2025/2/11-3/19）：**+10%**（原文口径，未复现验证） |
| **观察指标及说明** | 经纪人指数类情绪指标（内地缺直接对应）；股价启动 vs 房价指数筑底的时间差 = 抢跑窗口 |

**观点解释**（分析者解读）：这是典型的**股价 = 领先指标的领先指标**层级链：情绪（经纪人指数）→ 股价 → 房价。抢跑的微观机制是 NAV 折价的预期收敛——买方不需要等到房价涨，只需要"房价不跌"的概率上调就足以重估。对择时的启示：**等右侧确认（房价转正）再买股价已经晚 1 个月 +10%**。风险：远端六阶段复盘显示，无基本面支撑的跟涨全部回吐——抢跑窗口的识别依赖"是否临近拐点"的事先判断，本篇靠香港映射给锚，链条是间接的。

### 观点 2.2：驱动切换——企稳初期靠利率，上行期靠基本面

| 要素 | 内容（忠实提取） |
|---|---|
| **观点内容** | 行业筑底后分两阶段：**初期=房贷按揭利率下行驱动**（流动性逻辑）；**持续上行期=基本面量价改善驱动**（利率无增量利好行情照样涨） |
| **逻辑依据** | 利率下行→"供平过租"（月供<租金）→购房成本逻辑兑现；该逻辑定价充分后，行情主导权交给量价数据本身 |
| **事实依据** | 阶段一（2025/4-8）：HIBOR 骤降+H 按破 3%+全面积段"供平过租"，股价 2025-04-09 抢跑（领先 5-07 HIBOR 骤降）至 08-13 **+34%**（超额 8%）；阶段二（2025/12-2026/2）：按揭利率平稳无催化，新二手房成交量创 5 年新高 + 中原指数 Q1 连续 5 周上涨累计 +3% → **+33%、超额 29%** |
| **数据依据** | 全程（2025/2/11-2026/2/27）：绝对 **+76%**、相对恒指超额 **+51%**；确立上行后"抗回撤强、非脉冲式"（原文口径，未复现验证） |
| **观察指标及说明** | 阶段判别：按揭利率与租金回报率剪刀差（阶段一信号）；成交量同比与价格环比（阶段二信号）——利率钝化但量价上行 = 已入阶段二 |

**观点解释**（分析者解读）：本质是一个**两因子轮动状态机**：利率因子先行（贴现率修复估值）、量价因子接棒（现金流修复基本面）。可操作含义：① 不同阶段盯不同仪表盘（阶段一盯利率、阶段二盯成交），用错指标会在阶段二误判"没有催化剂"；② 确立上行后持有逻辑从博弈变配置（回撤浅、延续强）。这与本工程 regime 思路同构——**行业内部也有自己的两阶段 regime**。证伪条件：利率不再下行且量价未接棒 = 中断在阶段一（香港 2024 年多次如此）。

### 观点 2.3：内地当前 ≈ 香港阶段一向阶段二过渡（量修复、价收敛、预期未一致）

| 要素 | 内容（忠实提取） |
|---|---|
| **观点内容** | 内地楼市处"阶段一→阶段二过渡区间"：成交量修复、价格跌幅收敛，但拐点预期未形成一致；对应股价特征 = 高波动低收益（4 月冲高后回吐），与香港阶段一吻合 |
| **逻辑依据** | 三证据对标：量能（对照香港 2024H2 放量）→ 价格（对照香港 2024-12 起跌幅收窄路径）→ 利率剪刀差（对照香港 2024-12"供平过租"） |
| **事实依据** | 内房股 2026-04-09~05-12 +26.0% 后回调 |
| **数据依据** | 量：春节后至 6-21，17 核心/15 非核心城市二手成交同比 **+16.4%/+35.0%**；价：70 城环比跌幅 2025-12 以来整体收窄（5 月小幅反复，最新一周各能级全线收窄，**上海连续多周正增**）；利率：2Q2025 以来按揭利率持续向百城租金回报率收敛（原文口径，未复现验证） |
| **观察指标及说明** | 见建议 3.1 两大信号 |

**观点解释**（分析者解读）：映射法的外推有效性建立在"两地周期同构"上——作者选香港为锚因其**先行完成**且市场结构可比（利率敏感+资产定价）。但内地与香港有两个结构性差异报告未展开：① 内地体量与分化（一线到三四线的传导链条长得多，香港是单一市场）；② 政策变量权重不同（内地供给端政策—收储/棚改的边际作用更大）。因此"未来一个季度温和上行"的判断实际是**Beta 打折的映射**。证伪条件：核心城市成交同比转负，或上海价格环比重新走阔。

## 3. 投资建议

### 建议 3.1：盯两大确认信号——公积金贷款利率（利率端）+ 上海二手房价环比（价格端）

| 要素 | 内容（忠实提取） |
|---|---|
| **建议内容** | 未来一个季度内房股有望温和上行，核心催化是基本面改善预期的确认；信号①利率端：LPR 调降空间收窄背景下**重点关注公积金贷款利率调整节奏**；信号②价格端：**核心城市二手房价格持续环比改善，尤其上海**（本轮率先企稳的领先城市） |
| **逻辑依据** | 香港映射：拐点确认前夜 = 价格环比收窄→转正的传导起点 + 利率剪刀差收敛；上海对标本轮香港"领先城市"角色 |
| **事实依据** | 上海冰山指数自 2026-01 下旬基本持续增长；公积金贷款额度已提升（利率调整是下一步空间） |
| **数据依据** | 见观点 2.3（原文口径，未复现验证） |
| **观察指标及含义说明** | 公积金利率下调公告 = 利率端催化兑现；上海二手价环比连续为正 = 阶段二开启确认——两者其一出现即验证"过渡"判断 |

**建议解释**（分析者解读）：两个信号的选择很讲究——公积金利率是**政策可观测、时点离散**的催化（事件驱动），上海价格是**市场可观测、时点连续**的确认（趋势驱动）。一快一慢互为校验：只有事件无价格 = 又一轮政策博弈脉冲（2021 以来 5 轮皆如此）；只有价格无事件 = 基本面自发修复（更健康）。这个"事件×趋势双确认"结构可直接移植为本工程的监测规则。

### 建议 3.2：推荐 华润置地、中国海外发展、建发国际集团、中国金茂、越秀地产、绿城中国

| 要素 | 内容（忠实提取） |
|---|---|
| **建议内容** | 当前为布局内资房企战略窗口期，沿"高 RNAV 折让+核心城市土储+低包袱"推荐上述六家 |
| **逻辑依据** | 港资复盘的"左侧抢跑+驱动切换"规律 + 内地阶段一→二过渡判断（建议 3.1）+ 系列二估值排序（观点 2.4） |
| **事实依据** | 香港全程样本：拐点前 1 个月启动至 2026-02-27 绝对 +76%/超额 +51% |
| **数据依据** | 动态 RNAV 折让与弹性（表10，截至 2026/6/24；原文口径，未复现验证） |
| **观察指标及含义说明** | 同建议 3.1；个股层面加监测月度销售同比（业绩先导） |

**建议解释**（分析者解读）：与前两篇推荐对照形成完整演化：系列一铺垫篇（0130）A股滨江/新城/招商蛇口（筹码四低）→ 系列二（0531）越秀/绿城/建发国际/中海外/龙湖（折价弹性）→ **本篇（0625）+华润/+金茂/-龙湖（收敛为六家，低包袱权重升）**。三篇连读 = 同一团队四个月内选股框架从"没人要"到"折得深"再到"折得深且干净"——每一步都对应市场位置前移，这是**左侧策略随周期推进收窄标准**的活教材。风险：全链条押注"香港映射成立"；若内地在阶段一停留更久（政策断档），六家港股标的的机会成本是 A 股高 ROE 标的（滨江类）继续跑赢。
