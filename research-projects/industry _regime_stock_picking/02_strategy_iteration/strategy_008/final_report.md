# 回测报告 — strategy_008（镜像闸门）

> 结论先行：**通过 —— 第二个全项（风险侧）超越基线的迭代。**
> 引擎口径（trades）：**净值 4.5535x / 年化 17.56% / 波动 13.39% / Sharpe 1.2754 /
> 回撤 −18.36% / 3,488 笔** vs 007 的 **4.5663x / 17.60% / 15.16% / 1.1449 / −22.52% / 4,224 笔**。

> ⚠ **本迭代的定位是"风险调整改进"，不是"收益改进"**。净值不升是设计已知的（§5）。

## 1. 迭代设计

见 `main_idea.md`。唯一改动 = 在 007 的两个 exposure 条件之后追加一行：

```python
if regime == "reversal" and sc_max >= 3.0:      # ★ 镜像闸门
    exposure = 0.0
```

`sc_max` = top3 三个行业中拥挤度 `signal_count` 的**最大值**（007 用的是 `sc_mean`）。
行业层 / 选股 / 缓冲 / 权重 / 成本 / 引擎全同 007。

**机制**：量能方向必须与价格方向一致 —— 动量周（买强）要有量能背书；反转周（买最弱行业）
要**缩量**（抛压枯竭才是底），top3 里任一行业仍在放量（`sc_max ≥ 3`）说明出清未完成 → 整周不参与。

## 2. 口径与自检

- 引擎：**权重引擎** `local_weight_backtest.py`；行情 `engine_market_weekly_indpre_rawpx.parquet`（原始价）
- 成本 3/13 bps、min 5、lot 100、初始 50 万；指标全部由 trades 推算
- **★ 自检通过**：本目录基线对照跑出 **4.5663x / 17.60% / 1.1449 / −22.52% / 4,224 笔**，
  与 strategy_007 冻结件**逐值一致** ⇒ 引擎无漂移
- 闸门实际关掉 **23 个满仓反转周**（反转周合格池共 54 周）
- ★ **exposure 在周频施加后再 expand** —— `expand_to_daily` 在周界日会把「只存在于上一周」的
  股票按旧权重留下（实测 2017-05-26 权重和 0.8228 而 weekly_plan 说该周空仓）；
  先展开再缩放会对不上冻结件（调试中曾得到 1.34 vs 3.6001）

## 5. 分析

**① 为什么净值不升、Sharpe 却升？**
关掉 23 个"放量反转周"移除了收益与波动都很高的一段暴露。这些周的收益均值本身不高
（被关周平均为负），但**波动远高于组合平均** —— 所以净值几乎不变、波动率从 15.16% 降到 13.39%。
**这是风险侧改进的典型形态。**

**② 改善的年度分布不均衡（重要）**：

> ⚠ **2026-10-16 修正**：初版本表口径有误（用了 `last(Y)/first(Y−1)` = **两年窗口**，数字整体偏高且错位）。
> 下表为**年内口径**（`first(Y)→last(Y)`），与 analysis_017 一致。

| 年 | 007 | 008 | 差(pp) | 年内最大回撤 007 | 年内最大回撤 008 |
|---|---|---|---|---|---|
| 2017 | 27.13% | 24.05% | −3.08 | −2.3% | −2.3% |
| 2018 | −2.45% | −7.53% | **−5.08** | −16.5% | −18.3% |
| 2019 | −0.31% | −4.37% | **−4.06** | −10.7% | −18.4% |

**008 在 2017~2022 让出收益（−3~−8pp/年），在 2023~2025 赢回（+1.7~+10.8pp/年）**；
回撤改善集中在 2024~2025（−22.5%→−11.8%、−17.0%→−8.8%）。
⇒ **"闸门在近期更有效"**。**归因见 analysis_017**：被关的反转周在 2017~2022 平均 **+0.08%**（白关）、
在 2023~2026 平均 **−1.03%**（有效），而两段的**信号特征完全同档** ⇒ 是**同样的信号、不同的结果**
（时变性），且 **007 的动量闸门同样在 2017/2019 误关**。这是本迭代最需要在后续盯住的一点。

## 6. 诚实标注

1. **净值不升**（4.5535 vs 4.5663，−0.3%）—— 卖点全在风险侧。若不接受"净利不增"的改进，
   这个迭代就不该采用。
2. **阈值 `sc_max ≥ 3` 是样本内选出的**（016 复盘扫过 4 个镜像变体，本迭代取最优）。
   缓解：`sc_max≥3` 与 `sc_mean≥2` 同处一个平台（Sharpe 1.23~1.28 / DD −18.4%），
   而 `≥4` / `≥3` 回落到 ≈007 —— **两档结构而非单点尖峰**。仍应补阈值网格防过拟合。
3. **年度分布不均衡**（§5-②）：收益与回撤改善都集中在 2023~2025，前段反而让出收益。
   样本内无法区分"真实时变有效性"与"近年拟合"。
4. **nav 留一分布很宽**（3.97~4.81）；虽然 nav 不是本迭代的卖点，但说明**收益侧的稳定性弱于
   风险侧**。
5. **方向 A（反转周在场率）未并入**：未过自身随机门槛（90 分位 < P95），且会把反转周在场数
   从 31 抬到 166（5.3 倍）—— 属性质改变而非参数微调；与 B 作用在同一层，混做无法归因。
   留待 strategy_009 单独测（需先补 ≥50 种子对照）。
