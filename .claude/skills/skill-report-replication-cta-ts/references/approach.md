# 量化方法提取规范（approach.md）

本文件是 **Step 3 量化方法提取**的依据，也是 LLM 生成 `02_approach/main_approach.md` 的参考。
**核心价值**：把研报的量化观点/思路/方法分类提取，沉淀为可复用参考（比回测更重要）。

## 一、方法分类 taxonomy（按大类归类，可加子类）

对原文出现的每个量化方法，归入以下大类：

| 大类 | 含义 | 典型方法 |
|------|------|---------|
| **regime 判断** | 市场状态识别（趋势/震荡） | TSI 信噪比、ρ 自相关、Hurst、马尔科夫切换、GARCH 状态 |
| **指标分析与比较** | 趋势/动量指标的权重结构与性质 | 时序动量、EMA、双均线、MACD、Kalman 滤波、HP 滤波 |
| **多指标融合** | 多信号组合 | 多周期共振、打分、机器学习加权、自适应窗口（Kaufman 效率比） |
| **止盈止损** | 退出机制 | 固定 %、ATR 静态、ATR 移动（吊灯）、逻辑证伪、时间强制退出 |
| **风险控制** | 仓位与组合风控 | vol-target、目标波动、相关性监控、流动性预警、全账户熔断 |

> 如原文方法跨类（如 Kalman 既是滤波又可用于 regime），按其主要作用归类，必要时在子类注明跨类用途。

## 二、每个提取方法必须包含的 5 部分（4.2）

对每个方法，在 `main_approach.md` 写：

1. **文中思路叙述总结**：研报怎么讲的（必要时引原文关键句，标注章节/页码）。
2. **方法原理的解释与分析**：用大白话讲清楚数学/经济学原理。如"所有线性趋势指标本质是历史收益的加权（Levine & Pedersen 2016），权重分布决定指标性质"。
3. **公式指标的提取**：精确公式（LaTeX/markdown 数学），变量定义。
4. **指标的必要推导**（可选）：如"累积信噪比 = μ·T / (σ·√T)，故延长窗口 T 可对抗 √T 增长的噪声"。
5. **方法的优缺点**：具体、可操作。如"均线：平滑抗噪但延迟；Kalman：自适应抗噪但参数敏感、计算重；MACD：捕捉加速但震荡市假信号多"。

## 三、main_approach.md 额外三节（2.1~2.3）

除上述分类方法外，文档末尾还须有：

- **衍生方法**：原文"提及但未采用"的方法（如 regime 主讲信噪比点估计，但提到马尔科夫链）。每项含：
  - 方法说明总结
  - 本文用 / 不用的原因（如"马尔科夫链对参数初值与样本分布敏感，样本外泛化存疑，故本文未采用"）
- **参考资料**：本方法提取所引用的论文/文献清单（作者、年份、标题、用于哪一项）。
- **未来探索**：原文对未来可能方向的探讨归纳（如"引入基本面/资金流外生指标降低 regime 时滞"）。

## 四、输出要求

- `02_approach/main_approach.md`：中文为主，公式/代码标识符可用英文。
- 含文字、公式、（原文图表截图，保留引用）。
- 不得臆造原文没有的方法；原文未明确的，标"原文未详述，据上下文推断"。
- `check_approach.py` 会检查：taxonomy 大类关键词、5 部分内容、衍生方法、参考资料、未来探索。

## 五、为什么方法提取比回测更重要

回测只验证"这篇研报在这个样本里是否有效"（一次性的）。**方法提取**沉淀的是可迁移的量化观点与工具——下次遇到别的品种/别的研报时，这些方法（TSI、ATR 吊灯、Kaufman 自适应窗口…）可复用、可组合。所以 main_approach.md 是本技能的首要把关产物。
