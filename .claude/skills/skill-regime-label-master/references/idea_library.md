# 思路库提取规范（idea_library.md）

## 数据源

`REPLICATION_ROOT`（.env）下文档齐全的复现项目（须同时有 main_approach.md / regime_methods.md / final_report.md）。

`build_idea_library.py` 脚本负责扫描和原始材料汇总；**4 方面总结由 agent 补充**（脚本生成的占位表 `<待补充>`）。

## 每篇研报/论文的思路提取 4 方面

| 方面 | 提取要求 |
|------|---------|
| **核心思路** | 一句话说清方法本质（如"用位移/路径长度衡量价格运动效率"） |
| **解决问题** | 该方法针对什么痛点（如"震荡市频繁假突破磨损趋势策略"） |
| **理论优缺点** | 方法论层面的优劣（如"可实时计算但局部急速变有滞后"）——从 main_approach.md 优缺点节提取 |
| **实证结果** | 研报实证的关键数字（如"测试集准确率 83.98%"）——从 final_report.md 提取 |

## 使用规范

迭代时（Step 2 第 2 环节）：
1. 从错误归因确定问题类型（如"高波动行情误判"）
2. 到思路库找解决同类问题的方法（如厦大的"布林带宽特征"、申万的"Volatility_past 特征"）
3. 在 main_idea.md 改进思路列**注明来源项目**（如"借鉴 hmm-index-timing 的多特征思路"）

## 维护

复现库新增项目后重跑 `build_idea_library.py` 刷新原始材料，agent 补充新项目的 4 方面总结。
