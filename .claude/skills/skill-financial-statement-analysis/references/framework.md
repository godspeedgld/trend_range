# 分析框架：六维度 × 三桶纪律

数据形态假设：东方财富四表导出（利润/资产负债/现金流/综合能力）× 40+ 期季度面板。
分析有两条轴：**时间轴**（趋势/拐点/背离——面板数据独有的能力）+ **当期轴**（结构/比率）。

## 口径铁律（先读这个，口径错全错）

| 表 | 口径 | 变换 |
|---|---|---|
| 利润表 / 现金流量表 | **YTD 累计**（"2026年6月"=上半年累计） | 同比 = 同财年同期比；单季 = 年内差分（Q1 直取，Q2=H1−Q1 …） |
| 资产负债表 / 综合能力表 | 时点值 / 当期比率 | 直接使用，**不做差分** |

## 六维度

### 1 成长性
营收 / 归母净利润：YTD 同比序列 + 单季值。看增速水平、拐点、收入与利润增速的裂口（费用/减值弹性）。

### 2 盈利质量
比率（ROE/净利率）+ **含金量 = 经营现金流净额 ÷ 净利润**（跨表，同为 YTD 口径）。
★ 银行语境：经营现金流由存贷款变动主导，该比值天然剧烈（±10 不奇怪），只跟踪不警示。

### 3 偿债与资本
- 银行 profile：核心一级（参考 7.5%）/ 资本充足率（参考 10.5%）/ 杠杆倍数；充足率下行 = 扩张快于资本补充
- 通用 profile：资产负债率 / 流动 / 速动比率

### 4 效率与资产质量
- 银行：**净息差 NIM（核心引擎）** / 收入成本比 / 不良率 / 拨备覆盖率（150% 参考线）。
  NIM 下行 + 不良上行 = 周期底部组合；拨备高 = 利润缓冲厚
- 通用：周转率体系（总资产/存货/应收）

### 5 勾稽与信号（借 financial-fraud-index 三桶纪律）
- **明确异常**：需直接证据（如四表期间错位、勾稽断裂）
- **弱信号**：单季突增（|环比|>60% 且 |值|>1亿）；现金流与利润连续 4 期反号
- **缺失数据**：表内未披露字段（如员工人数仅年报）、源本身没有的（同行/持仓）——显式列出，不掩盖
- 铁律：**缺失显示"—"，宁缺毋错**（旧版 sparkline 技能抓错列产出 206.71 vs 真实 706.17 的教训）

### 6 指标全景
综合能力表核心项矩阵：历史首值 / 上期 / 最新 / 变动 / 最新期。

## 数字纪律
- 报告中每个数字必须从面板真算，解析层带抽查断言（首末期与东财原表肉眼比对行）
- 原表值是"亿元"口径（表头注明），不要自行再缩放
