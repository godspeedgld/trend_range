## 银行股解读的三条行业常识（写分析文字时用）

1. **NIM 与不良是双主线**：营收增速 ≈ 量（贷款规模）× 价（NIM）− 减值；NIM 收窄是全行业 Beta，
   个股 Alpha 看负债成本管控与不良认定严格度。
2. **利润的可调节性**：拨备覆盖率从 300% 降到 250% 可释放大量利润——看净利润增速必须同时看
   拨备变动方向（多提 = 藏利润，少提 = 释放）。
3. **经营现金流对银行无信号意义**（存贷款变动主导），勾稽分析只做利润表内部（营收−支出−减值→净利）
   与资本充足率的交叉验证。

## 与通用 profile 的差异清单
- 不算毛利率/存货/应收周转（无此科目或无意义）
- 偿债不看流动比率（负债是存款不是债），看资本充足率
- 现金流背离信号降级为"仅跟踪"
