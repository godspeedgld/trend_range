## 3. 因子构建

因子可能是**组合构造**（多因子分层合成）——**每一层的每个（子）因子都要独立提取**：
定义、量化表达、逻辑解释，一项不落。
例：方正「潮汐因子」由强潮汐因子 + 弱潮汐因子合成 → 两个子因子各自完整提取；
「适度冒险」= 月耀眼波动率 ⊕ 月耀眼收益率，两侧又各由月均/月稳合成 → 逐层提取。

**构建层级图**（提取者整理）：

```
<最终因子> = <子因子A> ⊕ <子因子B>（合成方式：等权/加权/回归…）
<子因子A> = …（逐层展开到原始指标）
```

### 3.1 <（子）因子名>

| 要素 | 内容 |
|---|---|
| **定义** | 一句话：这个因子度量什么 |
| **量化表达** | 公式照抄 + 变量逐个解释（给到"照着能写代码"的精度；参数、窗口、频率写全） |
| **逻辑解释** | 为什么这样构造能捕捉第 2 节的逻辑（作者表述；未明确则标注） |
| **关键细节/含糊处** | ⚠ 原文未明确的口径（如剔除边界、复权、数据源处理）逐条列出 |

### 3.2 <（子）因子名>

（同上结构；因子有多少层/多少个就复制多少节）

### 3.N 合成方式

| 要素 | 内容 |
|---|---|
| **量化表达** | 合成公式（等权平均/zscore 相加/回归残差/排序打分…） |
| **方向** | 最终因子是正向（越大越好买）还是负向（越小越好买）；原文标注方式 |
| **逻辑解释** | 为什么这样合成（作者表述） |
