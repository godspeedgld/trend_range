## 2. 现象观察

作者观察到的事实/统计规律——**这是量化思路的来源**，务必写清：
- 观察对象（指数/个股/行业；样本区间；样本数）
- 统计量（相关系数/分位/胜率/IC…）与具体数值
- 现象的方向与稳定性（跨时段是否一致）

> 若原文只给结论不给统计量，如实标注——**这一步决定了后续思路可不可信**。

## 3. 量化思路

把「现象」翻译成可交易的假设，回答：
- **什么条件下**触发（择时信号 / 截面排序 / 状态划分）
- **做什么方向**（多空 / 只多 / 只减仓）
- **赚什么钱**（趋势延续 / 均值回复 / 风险溢价 / 拥挤度反转）
- **为什么成立**（作者给的经济学/行为学解释）
