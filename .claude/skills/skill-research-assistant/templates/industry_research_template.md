## 2. 核心观点

一份研报通常含**多个观点要点**，每个要点独立成块、按同一模式提取。

**拆分规则**：作者把一组并列因素作为核心观点时，每个因素各算一个要点。
例：观点「地产行业三个关键因素：公积金利率、核心城市房价、人民币汇率」
→ 拆为 3 个要点（公积金利率 / 核心城市房价 / 人民币汇率），分别按下表提取与解释。

### 观点 2.1：<要点名>

| 要素 | 内容（忠实提取） |
|---|---|
| **观点内容** | 研报原文主张了什么 |
| **逻辑依据** | 研报给出的推理链条（因果/传导机制） |
| **事实依据** | 研报列举的事实（政策、事件、产业动态） |
| **数据依据** | 研报引用的数据与数字（标「原文口径，未复现验证」） |
| **观察指标及说明**（可选） | 研报给出的跟踪指标：名称 / 含义 / 阈值或方向（如何用它验证观点） |

**观点解释**（分析者解读，非原文内容）：
从经济学（供需/价格机制/利率传导/周期）、产业规律（竞争格局/产能周期/渗透率）等角度，
解释该观点为什么成立、传导路径是什么、可能失效的条件是什么。

建议与观点的对应关系在「建议解释」里点明。

### 建议 3.1：<要点名>

| 要素 | 内容（忠实提取） |
|---|---|
| **建议内容** | 研报建议的具体动作（超配/回避/关注方向/标的） |
| **逻辑依据** | 研报给出的推荐逻辑 |
| **事实依据** | 研报列举的支持事实 |
| **数据依据** | 研报引用的数据与数字（标「原文口径，未复现验证」） |
| **观察指标及含义说明**（可选） | 研报给出的跟踪指标：名称 / 含义 / 阈值或方向（指标怎么走时兑现或证伪建议） |
