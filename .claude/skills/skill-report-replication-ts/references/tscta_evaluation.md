# 时序 CTA 策略评估与三要素抽取清单

本文件是 Step 3（策略逻辑抽取）与 Step 5（评估报告）的依据。**与因子版的核心差异**：不做 IC/分位/多空等截面分析；评估聚焦"策略净值 + 风险/收益 + 分 regime + 基准对照"。

## 一、三要素抽取清单（Step 3，从研报里"找出来"）

时序 CTA 策略一般由三部分组成。`strategy_summary.md` 必须明确每项从研报何处抽取（引用原文公式/章节），`reference_implementation.py` 必须可审计地实现：

### 1. 开仓（Entry）
- 触发信号：时序动量 / 均线交叉 / 突破 / RSI 反转 / Kalman 状态 / 其他。
- 方向：多 / 空（direction ∈ {1,-1}）。
- 触发条件：阈值、窗口、确认机制（如连续 N 日）。
- 是否依赖市场状态（趋势态才开趋势仓，震荡态切反转）。

### 2. 止损（Stop-loss）
- 类型：固定百分比 / ATR 静态 / **ATR 移动（吊灯）** / 逻辑证伪。
- 参数：ATR 周期、倍数 k（如 k∈[1.5,4.5]）、是否对 TR 做 5%-95% 分位截尾。
- 触发后：`direction = 0`（平仓）。
- 在 `strategy.py` 用 OHLC 判断命中（日频口径）。

### 3. 止盈/退出（Take-profit / Exit）
- 类型：移动止盈（跟随极值）、时间强制退出（超预期窗口未获利则退）、目标位、逻辑证伪（市场状态切换）。
- 震荡态反转单的退出：如 RSI 回落阈值。
- 参数：持有上限、回归阈值。

### 参数与风控
- 窗口/倍数/阈值汇总；成本（手续费 bps）、滑点、保证金、合约乘数、杠杆、单品种最大权重、资金分配。

## 二、TSCTA 评估指标（Step 5）

以下为时序 CTA 的标准评估口径（引擎 `local_backtest.py` 的 `compute_metrics` 已覆盖大部分）：

### 收益/风险
- NAV（净值曲线）、总收益、**年化收益**、年化波动、**下行波动**。
- **Sharpe** = 年化收益 / 年化波动。
- **Sortino** = 年化收益 / 下行波动。
- **Calmar** = 年化收益 / |最大回撤|。
- **最大回撤 Max DD**、最大回撤持续期。
- **胜率**（Win Rate）、盈亏比（Profit/Loss，可由 trades 推）。
- 偏度/峰度（收益分布，条件允许时）。

### 换手与成本
- 平均换手、总成本、成本敏感性（不同 cost_bps 下的 Sharpe/Calmar）。

### 时序稳健性
- IS/OOS 切分、walk-forward（多窗口滚动）、逐年/逐月表现。
- 滚动 Sharpe / 滚动回撤。

### 分市场状态（Regime）
- 若研报定义了市场状态（如 TSI/ρ 或趋势-震荡），按状态拆分净值/指标。
- 趋势态 vs 震荡态分别的表现，验证"状态自适应切换"的价值。

### 基准对照（必需）
- **买入持有（Buy & Hold）**：标的不做空、满仓持有。
- **恒空仓 / 零收益（Always Flat / Zero Return）**。
- 消融对照（条件允许）：单开仓无止损、单止损无止盈、单状态（恒趋势/恒震荡）。
- 定种随机信号（阴性对照，可选）。

## 三、评估报告写作要求（摘自 output_contract）

- 中文正文，图内英文 ASCII。
- 顶部"阅读指南"+ 指标字典（NAV/Sharpe/Calmar/Sortino/Max DD/胜率/盈亏比/换手/IS/OOS）。
- 每图 5 段释义：回答什么/怎么看/看到了什么/意味着什么/数据来源。
- RAG 红黄绿打分卡：覆盖 数据覆盖、三要素完整度、回测是否真跑、Sharpe/Calmar/Max DD、成本稳健、基准对照。
- 明确"已知局限"：日频 bar、止损为 direction 近似（非 intraday 原生）、gap 风险。
- 最终结论：effective / weakly effective / ineffective / regime-dependent / inconclusive。

## 四、时序 CTA vs 截面因子（为何去掉 IC/分位）

- IC/RankIC/ICIR/分位组合/多空腿是**截面**概念（同一期 N 品种排序）。
- 时序 CTA 每品种按**自身**信号独立多空，无截面排序，IC/分位不适用。
- 故本技能不产出 IC/分位/多空图表，聚焦上述净值/风险/regime 口径。
