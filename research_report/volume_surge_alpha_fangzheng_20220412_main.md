## 1. 研报背景

成交量被认为是股票市场的原动力，俗语「量在价先」反映成交量的变化对价格波动具有指示性。
作者从**成交量的边际变动**（而非水平）出发，挖掘其对股票收益的潜在影响。

**理论动机**：引用 Arnold, Pelster & Subrahmanyam (2022, JFE) ——
「那些吸引人们注意的股票，更容易诱发人们去承担过度的风险」。
故成交量激增（=吸引注意）之后的**冒险程度是否"适度"**，可能定价后续收益。

**此前方法的不足**：**原文未明确**（未系统评述已有量能因子的缺陷，直接切入自己的构造）。

## 3. 量化思路

**触发条件**：日内分钟成交量出现**激增**的时刻。

**核心推理链**（以利好信息为例）：
```
利好信息公布 → 个股成交量突然放大（激增）
  ├─ 激增但价格不动   → 信息未被市场广泛认可  ┐
  └─ 激增且价格大涨   → 市场反应过于趋同/过度 ┘ → 两者都不理想
∴ 希望：激增带来价格的【适度】变化与波动
```

**方向**：**负向因子** —— 越"适度"（越接近市场平均水平）越好。

**赚什么钱**：**投资者注意力驱动的过度冒险 → 后续修正**（过度反应反转），
外加对"信息未被认可"情形（涨不动）的回避。

**为什么成立**：Arnold et al. (2022) 的注意力触发假说；作者未提供独立的市场微观结构证据。

## 4. 量化算法 / 指标

**参数总览**：激增阈值 = **均值 + 1 倍标准差**；关注窗口 = **激增时刻及其后 4 分钟（共 5 分钟）**；
聚合成月频用 **最近 20 个交易日**；两次使用**当日截面均值**（全市场个股横向比较）。

| 指标 | 定义 / 公式 | 参数 | 取值含义 | 窗口 |
|---|---|---|---|---|
| 成交量增加量 | `ΔV_t = V_t − V_{t−1}` | 分钟频 | 该分钟成交量的边际变化 | 日内 |
| **激增时刻** | `ΔV_t > mean(ΔV_d) + std(ΔV_d)` | 1×std | 标记该分钟为激增时刻 | 当日 d 内 |
| 耀眼5分钟 | 激增时刻 t 及其后 4 分钟 `[t, t+4]` | 5 分钟 | 投资者反应"最充分最强烈"的窗 | 日内 |
| 耀眼波动率 | `std(该 5 分钟内的分钟收益率)` | 用分钟收盘价算收益 | 激增引起的**价格波动** | 5 分钟 |
| 日耀眼波动率 | `mean(当日所有耀眼波动率)` | | 波动层面的反应代理 | 当日 |
| **适度日耀眼波动率** | `\|日耀眼波动率 − 当日截面均值\|` | 截面=当日全市场个股 | 与市场平均水平的**距离** | 当日 |
| 月均耀眼波动率 | `mean(最近20日 适度日耀眼波动率)` | 20 日 | 适度程度的**水平** | 月频 |
| 月稳耀眼波动率 | `std(最近20日 适度日耀眼波动率)` | 20 日 | 适度程度的**稳定性** | 月频 |
| **月耀眼波动率** | 月均与月稳**等权合成** | | 合成波动侧因子 | 月频 |
| 耀眼收益率 | 激增时刻**那一分钟**的收益率（**非区间**） | 分钟收盘价 | 激增引起的**价格变动** | 分钟 |
| 日耀眼收益率 | `mean(当日所有耀眼收益率)` | | 收益层面的反应代理 | 当日 |
| 适度日耀眼收益率 | `\|日耀眼收益率 − 当日截面均值\|` | 同上 | 与市场平均的距离 | 当日 |
| 月均 / 月稳耀眼收益率 | 最近 20 日的 `mean` / `std` | 20 日 | 水平 / 稳定性 | 月频 |
| 月耀眼收益率 | 月均与月稳**等权合成** | | 合成收益侧因子 | 月频 |
| **适度冒险因子** | 月耀眼波动率 ⊕ 月耀眼收益率，**等权合成** | | **最终因子（负向：越小越好）** | 月频 |

**关键细节与含糊处**：

1. **「剔除开盘和收盘数据，仅考虑日内分钟频数据」** —— ⚠ **剔除了哪几分钟原文未明确**
   （只说了原则，未给分钟数；图表 1/6 的示意也无法反推具体边界）。
2. **「耀眼波动率」用区间**（5 分钟的标准差）；**「耀眼收益率」只用单点**（激增那一分钟）——
   两者口径**不对称**，这是原文设计，不是笔误。
3. **「适度」的基准是当日全市场截面均值**，不是个股自身历史均值 → 需要**全市场横截面**数据。
4. 两个"月均/月稳"命名：**均 = 均值，稳 = 标准差**（作者自己定义，非通用术语）。
5. 复权口径、数据源精细处理：**原文未明确**（数据源标注为 Wind）。
