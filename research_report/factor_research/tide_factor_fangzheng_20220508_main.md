## 1. 研报背景

多因子选股系列第二篇，延续"量在价先"主线：系列之一看**量能激增的时点**（耀眼5分钟），
本篇看**日内成交量的完整形态**——把个股每天"量由低到高再回到低"的更替过程类比为一次"潮汐"，
从潮汐过程伴随的价格变动中挖 alpha。

---

## 2. 因子逻辑

| 来源类型 | 内容（忠实提取，原文口径） |
|---|---|
| **观察现象** | ① 个股每个交易日 240 分钟里成交量有高有低——高时"宛如高潮，交投活跃、价格波动相对较大"，低时"犹如低潮，交易清淡"（图表4/5/6 示意）；② 万得全A 分钟成交量整体呈"开盘后逐步下降、临收盘再提升"形态，但**个股并不严格同步**（图表3，与系列之一相同观察） |
| **交易经验** | "量在价先"；技术分析中成交量是"股票市场的原动力"；另有"天量天价""地量地价"案例（图表1/2） |
| **经济学/行为金融理论** | **反应过度**：潮汐中价格快速下跌 = 原有投资者过分悲观、急于抛售 → 反应过度 → 未来可能**补涨**；价格快速上涨 = 新进投资者过分乐观、急于建仓 → 反应过度 → 未来回落。⚠ 本篇**未引用外部文献**（系列之一引了 Arnold et al. 2022，本篇没有） |
| **其他** | — |

**逻辑链**（分析者整理自原文）：

```
一次潮汐（日内量能 蓄势→顶峰→消退 的完整周期）
  → 潮汐过程的价格变动【速率】= 投资者买卖意愿强烈程度的代理
  ├─ 速率大（跌得急）→ 原持有人过分悲观、恐慌抛售 → 反应过度 → 未来补涨
  └─ 速率大（涨得急）→ 新进者过分乐观、抢筹建仓 → 反应过度 → 未来回落
∴ 潮汐内价格变动速率越【极端（快）】→ 未来越倾向反向修正 → 负向因子
```

> ⚠ 提取者注：负向方向的含义与系列之一不同——之一惩罚"**离适度远**"（双向），
> 之二惩罚"**速率快**"（无论涨跌方向都快），两者同属"反应过度→修正"家族。

## 3. 因子构建

**构建层级图**（提取者整理）：

```
完整潮汐因子（负向：越小越好）
 = 强势半潮汐因子 ⊕ 稳定弱势半潮汐因子（等权合成）
底层：分钟量 → 邻域成交量(9分钟和) → 顶峰/涨潮/退潮三锚点 → 半潮汐价格变动速率 → 20日聚合
另：全潮汐因子（整段速率·20日均值）单独测试，【未进入】最终合成（原文未解释为何弃用）
```

### 3.1 邻域成交量（原料·平滑）

| 要素 | 内容 |
|---|---|
| **定义** | 每分钟成交量及其前后各 4 分钟成交量之和，用于减小个别异常点影响 |
| **量化表达** | `邻域V_t = Σ V_k, k ∈ [t−4, t+4]`（9 分钟窗口和） |
| **逻辑解释** | 对分钟量做 9 分钟平滑后再找极值，抗噪 |
| **关键细节/含糊处** | ⚠ 日内边界分钟（前/后不足 4 分钟）的窗口怎么取（截断还是缺失）**原文未明确** |

### 3.2 潮汐三锚点：顶峰 / 涨潮 / 退潮（核心结构定义）

| 要素 | 内容 |
|---|---|
| **定义** | 顶峰时刻 t = 邻域成交量**最高**的分钟；涨潮时刻 m = 第 5 ~ t−1 分钟里邻域成交量**最低**的分钟（邻域量 Vm、收盘价 Cm）；退潮时刻 n = 第 t+1 ~ 233 分钟里邻域成交量**最低**的分钟（Vn、Cn） |
| **量化表达** | `t = argmax(邻域V)`；`m = argmin(邻域V, k ∈ [5, t−1])`；`n = argmin(邻域V, k ∈ [t+1, 233])` |
| **逻辑解释** | 涨潮 = m→t（量能从低蓄到顶峰），退潮 = t→n（从顶峰退到低），**潮汐 = m→n 全过程**（每天一次） |
| **关键细节/含糊处** | ① 搜索区间写死 **第 5 分钟起、第 233 分钟止** —— 推断剔除开盘后前 ~4 分钟与收盘前最后 ~7 分钟，但原文文字只说"剔除开盘和收盘数据"，**未逐字给出边界**（区间数字是从公式反推的唯一线索）；② 最高/最低点并列时取哪个**原文未明确**；③ 每天是否恒有"一次完整潮汐"（如 t 极靠边导致某段为空）**原文未明确** |

### 3.3 全潮汐因子（整段速率·单独测试，未进合成）

| 要素 | 内容 |
|---|---|
| **定义** | 一次潮汐全过程（m→n）的价格变动速率，作为"投资者出售或购买意愿强烈程度"的日频代理 |
| **量化表达** | `日速率 = (Cn − Cm) / Cm / (n − m)`（涨跌幅 ÷ 持续分钟数；C 为分钟收盘价）；`全潮汐因子 = mean(日速率, 最近 20 交易日)` |
| **逻辑解释** | 单位时间的价格变动 = 买卖意愿强度 |
| **关键细节/含糊处** | n−m 为分钟数；20 日为月频聚合窗口（与系列之一一致） |

### 3.4 强势/弱势半潮汐拆分（按能量）

| 要素 | 内容 |
|---|---|
| **定义** | 以顶峰 t 为界把潮汐拆成两段；**起点/终点量更低的那段需要更强的推动力量 → 是"强势半潮汐"**，另一段为"弱势半潮汐" |
| **量化表达** | `若 Vm < Vn：涨潮(m→t) = 强势，退潮(t→n) = 弱势`；`若 Vm > Vn：退潮(t→n) = 强势，涨潮(m→t) = 弱势`（量差决定归属，哪只股票哪天属哪种情形逐日判定） |
| **逻辑解释** | "成交量跨度更大，需要更强的力量来推动，因此包含的信息密度也更大" |
| **关键细节/含糊处** | Vm = Vn 的平局情形**原文未明确** |

### 3.5 强势半潮汐因子

| 要素 | 内容 |
|---|---|
| **定义** | 强势半过程的单位时间价格变动速率（买卖意愿更强的时段的热情代理），20 日均值 |
| **量化表达** | `日速率 = 强势段涨跌幅 ÷ 强势段持续分钟数`（起止均为该段两锚点的分钟收盘价）；`因子 = mean(日速率, 20日)` |
| **逻辑解释** | 信息密度大的时段更能预测未来收益 |
| **关键细节/含糊处** | 强势段是 m→t 还是 t→n 逐日可变（见 3.4） |

### 3.6 弱势半潮汐因子（两种刻画，稳定版入选）

| 要素 | 内容 |
|---|---|
| **定义** | 弱势半过程的单位时间价格变动速率；聚合方式两种：**激进**=最近 20 日速率**均值**，**稳定**=最近 20 日速率**标准差** |
| **量化表达** | `激进弱势 = mean(弱势段日速率, 20日)`；`稳定弱势 = std(弱势段日速率, 20日)` |
| **逻辑解释** | 原文（回测后）："对于弱势半潮汐过程，**求稳是更重要的**……更希望它可以每日保持相对稳定，为强势半潮汐做足准备或做好收尾"——即弱势段的**波动（不稳定）**才是不利信号，其水平反而不重要 |
| **关键细节/含糊处** | ⚠ "稳定版更好"是**看了回测结果后**的选择性保留（激进版 IC 仅 −2.69%、IR 1.40，被弃）——存在**多重比较/事后选择**风险，提取者标注 |

### 3.7 合成方式

| 要素 | 内容 |
|---|---|
| **量化表达** | `完整潮汐因子 = 等权(强势半潮汐, 稳定弱势半潮汐)`（仅两个子因子；**全潮汐与激进弱势未进入**） |
| **方向** | **负向因子**（速率越快未来收益越差；IC 为负） |
| **逻辑解释** | 原文依据回测表现挑选（"表现均较为出色"的两只合成）；⚠ 为何弃用 IC 更高的全潮汐（−7.09%）**原文未解释** |
