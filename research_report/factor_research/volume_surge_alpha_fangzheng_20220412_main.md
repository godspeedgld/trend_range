## 1. 研报背景

多因子选股系列第一篇。作者从技术分析的核心信条出发——成交量被认为是"股票市场的原动力"，
俗语"量在价先"表明成交量变化对价格波动有指示性——尝试**从成交量的边际变动**（而非成交量水平）
出发，挖掘其对股票收益的潜在影响；数据粒度下沉到**分钟频**，构造月频选股因子。

---

## 2. 因子逻辑

| 来源类型 | 内容（忠实提取，原文口径） |
|---|---|
| **观察现象** | ① 万得全A 分钟成交量呈"开盘后逐步下降、临近收盘再提升"的日内形态（图表2）——但这是**市场整体**规律；② **个股并不严格同步**，成交量大幅变动的情况"较为频繁"；③ 贵州茅台、宁德时代 2020 年以来日内「激增时刻」次数**均值都是 22 次**；行业均值：国防军工/计算机/电子较多，商业贸易/房地产/交通运输较少（图表5） |
| **交易经验** | "量在价先"——成交量的变化对股票价格波动具有指示性作用 |
| **经济学/行为金融理论** | Arnold, Pelster & Subrahmanyam (2022, JFE 143(2): 846-875)：**"那些吸引人们注意的股票，更容易诱发人们去承担过度的风险"** |
| **其他** | — |

**逻辑链**（分析者整理自原文第 2 节）：

```
利好信息公布 → 个股成交量突然放大（激增）
  ├─ 激增但价格不动/波动小 → 利好未被市场广泛认可     ┐
  └─ 激增且价格大幅上涨   → 市场反应过于趋同（反应过度）┘ → 两者都不理想
∴ 期望：认可利好的人【适度】承担风险 → 激增带来价格的【适度】变化与波动
因子 = 度量个股激增反应与"市场平均适度水平"的距离 → 距离越大未来收益越差（负向）
```

> ⚠ 提取者注：「适度最好」（与市场平均的距离）是核心设计，但**来自行为金融推理，
> 原文未提供独立的市场微观结构证据**；截面均值被直接当作"适度"基准（原文称"为了不引入
> 其他参数"）。

## 3. 因子构建

**构建层级图**（提取者整理）：

```
适度冒险因子（负向：越小越好）
 = 月耀眼波动率 ⊕ 月耀眼收益率（等权合成）
月耀眼波动率 = 月均耀眼波动率 ⊕ 月稳耀眼波动率（等权）
月耀眼收益率 = 月均耀眼收益率 ⊕ 月稳耀眼收益率（等权）
底层：分钟量差 ΔV → 激增时刻 → 耀眼5分钟/耀眼收益率
      → 日耀眼波动率/日耀眼收益率 → 适度日耀眼值（减当日截面均值取绝对值）→ 20日 mean/std
```

### 3.1 成交量增加量（原料）

| 要素 | 内容 |
|---|---|
| **定义** | 个股每分钟成交量相对上一分钟的差值（分钟量能的边际变化） |
| **量化表达** | `ΔV_t = V_t − V_{t−1}`（V = 分钟成交量；t = 日内分钟序号） |
| **逻辑解释** | 用"边际变动"而非水平来捕捉市场注意力的突发聚焦 |
| **关键细节/含糊处** | ⚠ 原文"剔除开盘和收盘数据，仅考虑日内分钟频数据"——**剔除了哪几分钟未明确**（只给原则，未给分钟数；图表示意也无法反推） |

### 3.2 激增时刻（触发器）

| 要素 | 内容 |
|---|---|
| **定义** | 当日分钟成交量增加量显著超过当日自身分布上限的时刻 |
| **量化表达** | 每天每只个股：`激增时刻 = { t : ΔV_t > mean(ΔV_d) + 1·std(ΔV_d) }`，其中 mean/std 为**该股当日**全部日内分钟 ΔV 的均值/标准差（阈值参数 = 均值 + **1 倍**标准差） |
| **逻辑解释** | 成交量激增 = 新信息/注意力事件到达的代理 |
| **关键细节/含糊处** | 阈值只用当日自身分布（非横截面）；例：第 9、10、88、200 分钟超标 → 这四个分钟均为激增时刻。原文实测个股日均激增时刻约 22 次（茅台/宁德时代） |

### 3.3 耀眼5分钟（观察窗）

| 要素 | 内容 |
|---|---|
| **定义** | 激增时刻那一分钟及其随后 4 分钟——投资者对激增的反应"最充分最强烈"的 5 分钟 |
| **量化表达** | 激增时刻 t → 窗口 `[t, t+4]`（含端点共 5 分钟）；多个激增时刻窗口可重叠（例：9→9~13、10→10~14） |
| **逻辑解释** | 反应集中在这 5 分钟内，度量它即可度量"反应形态" |
| **关键细节/含糊处** | 窗口可重叠、不合并；敏感性测试改 3/4 分钟（见 §4） |

### 3.4 耀眼波动率 → 日耀眼波动率（波动侧日频代理）

| 要素 | 内容 |
|---|---|
| **定义** | 单个耀眼5分钟内收益率的标准差；当日全部耀眼波动率的均值为"日耀眼波动率" |
| **量化表达** | `耀眼波动率_w = std( r_t , …, r_{t+4} )`，r 为**分钟收盘价**算的分钟收益率；`日耀眼波动率_d = mean(w ∈ 当日全部耀眼5分钟)` |
| **逻辑解释** | 激增引起的**价格波动**层面的反应强度 |
| **关键细节/含糊处** | 用分钟收盘价；std 口径（样本/总体）未明确；⚠ 窗口内取 **4 个还是 5 个**分钟收益率原文未明 —— 自然读法：收益率逐分钟全局定义（`r_t=c_t/c_{t−1}−1`）后取窗口内 std ⇒ **5 个**（第 t 分钟的收益率用到 t−1 收盘，跨出窗口一格）；若只用窗口内收盘两两算则 4 个。复现时需自定并记录（2026-09-29 对证原文后补注） |

### 3.5 耀眼收益率 → 日耀眼收益率（收益侧日频代理）

| 要素 | 内容 |
|---|---|
| **定义** | 激增时刻**那一分钟**的收益率（单点，非区间）；当日全部耀眼收益率的均值为"日耀眼收益率" |
| **量化表达** | `耀眼收益率_t = r_t`（激增分钟 t 的分钟收益率）；`日耀眼收益率_d = mean(当日全部耀眼收益率)` |
| **逻辑解释** | 激增引起的**价格变动**（方向性）层面的反应 |
| **关键细节/含糊处** | ⚠ 与波动率侧口径**不对称**：波动率用 5 分钟区间、收益率只用激增单点——这是原文设计，非笔误 |

### 3.6 适度日耀眼波动率 / 适度日耀眼收益率（"适度"核心变换）

| 要素 | 内容 |
|---|---|
| **定义** | 个股日频代理与**当日全市场截面均值**的距离（绝对值） |
| **量化表达** | `适度日耀眼波动率 = |日耀眼波动率 − mean_全市场(日耀眼波动率, 当日)|`；收益率侧同构 |
| **逻辑解释** | "适度"的基准 = 当日截面均值（原文：为不引入其他参数）；离市场平均越远 = 越不适度（过度反应或未被认可） |
| **关键细节/含糊处** | 截面 = **当日全市场个股**横截面 → 复现需全市场数据，不能只算池内（池内近似是口径偏离） |

### 3.7 月均 / 月稳耀眼波动率（20 日聚合·波动侧）

| 要素 | 内容 |
|---|---|
| **定义** | 适度日耀眼波动率最近 20 个交易日的**均值**（均=水平）/ **标准差**（稳=稳定性） |
| **量化表达** | `月均耀眼波动率 = mean(适度日耀眼波动率, 最近20交易日)`；`月稳耀眼波动率 = std(同, 20日)` |
| **逻辑解释** | 均值捕捉适度程度的水平、标准差捕捉其持续性/稳定性 |
| **关键细节/含糊处** | "月均/月稳"为作者自定义命名（均=mean、稳=std），非通用术语；std 口径未明确 |

### 3.8 月均 / 月稳耀眼收益率（20 日聚合·收益侧）

与 3.7 完全同构，把输入换成"适度日耀眼收益率"。

### 3.9 合成方式

| 要素 | 内容 |
|---|---|
| **量化表达** | `月耀眼波动率 = 等权(月均耀眼波动率, 月稳耀眼波动率)`；`月耀眼收益率 = 等权(月均耀眼收益率, 月稳耀眼收益率)`；`适度冒险因子 = 等权(月耀眼波动率, 月耀眼收益率)`（共 **2 层等权合成**、4 个 20 日聚合子因子） |
| **方向** | **负向因子**（值越小=越适度=未来收益越好；IC 为负） |
| **逻辑解释** | 波动侧与收益侧分别度量"过度"的两个维度，等权合并（原文未解释为何等权而非加权） |
