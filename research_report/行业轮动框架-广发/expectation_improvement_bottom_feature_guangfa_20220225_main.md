## 1. 研报背景

- 作者给「完善的行业轮动框架」的定位：通常涵盖**宏观变量解读、行业景气度分析、行业微观变化**三个维度。
- 本篇取**微观变化**视角：挖掘行业的「**长期底部**」「**短期动量**」「**预期改善**」「**资金流入比较高**」四个微观特征，筛选出**暂时落入底部并有可能触底反弹**的行业，为提前布局提供启发。
- 出发点（原文）：**"便宜"的股票安全性更高、增长潜力也更大，处在探底回升阶段的股票往往具有更强的吸引力。** 但同时强调需兼顾基本面（业绩是否优良、是否具高成长性）。

## 2. 现象观察

### 2.1 2021 年的行业结构分化与阶段性底部

- 图 1（2017-2021 全行业涨跌幅 vs 2021 单年度）：2021 年**涨幅高**——电机、稀有金属、其他采掘、电源设备、化学原料；**处于底部**——保险、机场、医药商业、白色家电、食品加工。
- **近四年**（2017-2021）：涨幅最高——电源设备、饮料制造、旅游综合、半导体、玻璃制造；跌幅最高——园林工程、运输设备、文化传媒、环保工程及服务、铁路运输。
- 图 2 / 图 3（2021 全年 vs 2021Q4）：**2021 全年跌幅大的行业在第四季度出现明显反弹**——保险、食品加工、饲料、文化传媒、营销传播、医疗器械、化学制药、白色家电等。

- **测法**：测算全行业**当月涨跌幅**与**过去 t 时间涨跌幅**的平均相关系数（2016 年以后，逐月）。

  |---|---|---|---|---|---|---|---|---|---|
  | 平均相关系数 | 0.017 | 0.013 | 0.016 | **0.061** | **0.057** | 0.034 | 0.018 | **−0.008** | **−0.002** |

## 3. 量化思路

**四特征 → 四因子 → 取交集**：

| 特征 | 刻画因子 | 方向 |
|---|---|---|
| 长期底部 | **长期均线因子**（长周期均线比值） | 取**比值小**（后 q 名） |
| 短期动量 | **短期均线因子**（短周期均线比值） | 取**比值大**（前 p 名） |
| 预期改善 | **盈利预期增速因子**（一致预期 ROE 月度增幅） | 取**前 40** |
| 资金流入比较高 | **资金流向因子**（北上资金流入比排名 + 净主动买入额占比排名） | 取**前 n** |

- **调仓频率**：月频换仓，**每个因子在每月最后一个交易日计算**。
- **窗口选择依据（原文）**：挖掘底部特征要选"探底时间足够长"的行业 → 长期均线因子参考 **半年~一年日均线 / 四年~五年日均线**；动量效应半年以内较明显 → 短期均线因子用 **1~3 个月日均线 / 半年~一年日均线**。
- **合成方式：交集（硬过滤），不是加权打分。**
- **兜底**：若当期四个条件的交集为**空**，则**直接配置全行业等权组合**。
- 作者自述的单因子先行测试逻辑：「如果单策略表现较好，则说明策略思路及因子的构造是有效的」，据此再复合。

## 4. 量化算法 / 指标

### 4.1 因子计算公式（原文表 1，逐字）

| 因子名称 | 计算方法 |
|---|---|
| 长期均线因子 | 过去 **i** 日均线 / 过去 **j** 日均线 |
| 短期均线因子 | 过去 **i** 日均线 / 过去 **j** 日均线 |
| 盈利预期增速因子 | （当月一致预期 ROE − 上月一致预期 ROE）/ **｜上月一致预期 ROE 的绝对值｜** |
| 资金流向因子 | 北上资金流入净值/流通市值 **排名** + 净主动买入额/流通市值 **排名** |

**变量解释（原文）**：
- **N 日均线 = N 日收盘价之和 / N**（即简单移动平均）。
- **一致预期 ROE**：ROE = 预期股本回报率，是"衡量盈利能力的关键指标"；作者用**一致预期 ROE 的环比增速**筛选"预期改善"行业。
- **资金流向因子 = 两个排名的相加**（不是比值）。

### 4.2 标的池

- 原文正文：对**申万二级 104 个行业**进行过滤，剔除**关注度较低或成分股较少**的行业，在剩余的 **82 个行业**中构建轮动策略（原文表 4 列出这 82 个行业名）。
- 基准：**剔除「其他休闲服务、其他轻工制造」后的全行业等权收益率**。
- ⚠ **原文内部口径不一致（照抄）**：摘要写「基于 **102 个**申万二级行业」，正文写「申万二级 **104 个**行业…剩余 **82 个**」。

### 4.3 筛选条件（原文表 5，逐字）

| 条件 | 因子表现 |
|---|---|
| 长期相对底部 | 长期均线因子**后 q** 个行业 |
| 短期反弹趋势 | 短期均线因子**前 p** 个行业 |
| 预期改善 | 盈利预期增速因子**前 40** 个行业 |
| 资金流入较快 | 资金流向因子**前 n** 个行业 |

> 原文说明：因盈利预期增速因子**前 40** 在回测中更好，且为保证每月超配行业数量均匀适中，**该因子固定取前 40**，再与其他因子结合。

### 4.4 ★ 最终参数（月频主策略，原文 §三(二) + 图 20）

| 因子 | 参数 |
|---|---|
| 长期均线因子 | **180 日均线 / 1100 日均线 后 40** |
| 短期均线因子 | **40 日均线 / 180 日均线 前 35** |
| 盈利预期增速因子 | **前 40** |
| 资金流向因子 | **前 35** |

### 4.5 季频对照的参数（与月频不同！）

| 因子 | 季频参数 |
|---|---|
| 长期均线因子 | 180 日均线 / 1100 日均线 后 40（同上） |
| 短期均线因子 | 40 日均线 / 180 日均线 **前 40**（月频是前 35） |
| 盈利预期增速因子 | 前 40 |
| 资金流向因子 | **前 50**（月频是前 35） |

### 4.6 案例（原文 §二(四)，用于展示因子取值）

| 案例 | 长期均线1 / 长期均线2（比值） | 短期均线1 / 短期均线2（比值） | 结果 |
|---|---|---|---|
| **石油化工**（2021-08-31 计算，2021-09 期） | 1964.57 / 2278.85 = **0.86**（小 → 底部） | 2089.46 / 1964.57 = **1.06**（高 → 动量） | 该行业 2021-09 **+11.16%**，全行业平均 **−1.5%** |
| **钢铁**（2021-03-31 计算，2021-04 期） | 2411.95 / 2706.34 = **0.89** | 2714.63 / 2411.95 = **1.13** | 该行业 2021-04 **+8.85%**，全行业平均 **+1.12%** |
| **稀有金属**（反例，2021-08-31） | 15495.40 / 9904.45 = **1.56**（高 → **不满足底部**） | 21902.17 / 15495.40 = **1.41**（高 → 满足动量） | 只满足动量、不满足底部 ⇒ 被排除 |

> 注：案例中"长期均线 2"= 1100 日 = "短期均线 2"= 180 日 —— 即**长期因子与短期因子的分母窗口不同**（案例里长期分母 1100 日、短期分母 180 日），与 §4.4 参数一致。

### 8.3 ⚠ 「交集法」与本工程的「排序 ≫ 开关」定律

本工程 analysis_001 六轮全负的核心教训是「**排序 ≫ 开关**」（行业信息当**硬过滤**没有正向价值）。
本篇的四因子**取交集**正是硬过滤结构 —— 且它自己披露了代价：**当期交集为空时配全行业等权**（说明空集不罕见）。
复现时应重点看**每期入选行业数量的分布**（原文未给），若长期只有 0~2 个行业，则等价于"极端收紧"。

### 8.4 可迁移的三个具体点

1. **一致预期 ROE 增速**（`(当月−上月)/|上月|`）—— 本工程从未用过**分析师预期类**信号（009 的拥挤度是量能类、
   014 的 COMBO 是个股量价类）。若 BigQuant 有一致预期数据，这是一个**全新信息源**。
2. **资金流向因子 = 北上资金流入比排名 + 净主动买入额占比排名**（两个排名**相加**）—— 与 memory 里
   `moneyflow-fetch-pending` 的待办（资金流数据拉取）直接衔接。
3. **月频 vs 季频的参数差异**（季频把短期因子放宽到前 40、资金流放宽到前 50）—— 说明**降频需同步放宽分位**，
   本工程若做降频版本可参考。
