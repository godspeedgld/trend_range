## 1. 研报背景

- 作者认为一个完善的行业轮动框架通常涵盖三块：**对宏观变量的解读、对行业景气度的分析、考虑个股微观特征**。
  此前作者已从不同角度构造过多个量化行业轮动模型，但**尚未形成完善的框架体系**（原文未指明是哪些模型）。
- 本文从**宏观视角**出发，研究行业轮动中有效的宏观驱动因素及逻辑，并探索可量化建模的方法。
- 动机来自对四种常见宏观分析方法的比较（§3），作者判定前三类都有硬伤，故选**宏观事件驱动法**。

## 3. 量化思路

**四类宏观分析方法的取舍（原文的比较）**：

| 方法 | 原文评价 |
|---|---|
| ① 样本分类法（如「美林时钟」） | 逻辑直观易操作，但**对样本分类存在显著滞后性**，实际应用偏差与争议较大 |
| ② 时间序列回归 | 简单，但**缺乏清晰逻辑且易过拟合**；实证上宏观变量与行业收益率**不显著相关**（表1） |
| ③ 模式匹配法（如技术分析） | 假设历史重复、**缺乏因果关系**；行业数量有限，统计上不构成大样本 |
| ④ **宏观事件驱动法** | 只针对**少数极端状态**；剔除大量可能无效的信息后，**结论更鲜明、有效性更显著** ← **本文采用** |

**可交易的假设链**：

- **触发条件**：某个（宏观 或 行业特有）指标触发某个**事件状态**（8 类之一，见 §4）。
- **方向**：只做多行业指数、不做空（原文明确）→ 因此仅保留「事件对行业下一期超额收益为正且稳定」的组合。
- **赚什么钱**：宏观/产业变量的**极端状态**预示行业**景气度**变化 → 行业指数相对收益。
  作者给出的经济学解释举例：流动性宽松利好休闲服务、原材料低价利好汽车、PPI 上行利好家电。
- **为什么事件法可行**（作者的逻辑）：极端状态剔除了大量无效信息，剩下的样本统计规律更稳定；
  且事件是**离散、可解释**的，规避了回归法的过拟合。

### 4.2 八类事件模式（原文表4，**K 为参数**）

| 事件模式 | 描述（原文） |
|---|---|
| 历史高点 | 因子创历史新高（**因子数据从 2007 年开始**） |
| 历史低点 | 因子创历史新低（同上） |
| 近期高位 | 因子 **>**（过去 **K1** 个月均值 **+ 2 ×** 过去 K1 个月**标准差**） |
| 近期低位 | 因子 **<**（过去 K1 个月均值 **− 2 ×** 过去 K1 个月标准差） |
| 连续上涨 | 因子值**连续上涨 K2 个月** |
| 连续下跌 | 因子值连续下跌 K2 个月 |
| 连续上涨后下跌 | 因子值**连续上涨 K3 个月后最新一期下跌** |
| 连续下跌后上涨 | 因子值连续下跌 K3 个月后最新一期上涨 |

- **K1 / K2 / K3 通过「样本内优化」确定**（原文明确；**具体取值原文未在各处统一给出**，
  但在**表6「各行业对应事件驱动表」**里以「事件模式(期数)」形式**逐行业列出**，如
  `近期高点(12 期)` / `连续下跌(4 期)` / `连续下跌后上涨(3 期)` → **可视为 K 的落库值**）。
- 「近期高/低位」的**倍数 2**（2 倍标准差）在表4 中固定写出，非参数。

### 4.3 有效事件的筛选（原文表5）

| 筛选标准 | 逻辑 | 阈值 |
|---|---|---|
| **因子事件 IR** = 每次事件发生后**下一期平均超额收益 / 超额收益的标准差** | |IR| 越大，事件对行业下一期收益的预测越稳定 | **\|IR\| > 0.7** |
| 历史上**因子事件发生次数** | 次数足够多才有统计意义 | **≥ 8** |

- **去重规则**：同一因子、同类型事件，若有**不同参数 K** 的事件同时满足两阈值 → **只保留 |IR| 最大的那一个**。
- 超额收益的基准 = **行业等权基准**（§5）。

### 4.4 行业配置算法（原文 §2.2 + §4.1）

1. 月初（**每月末交易日**）对**每个行业**用其**自己的有效事件库**逐一检测；
2. 有事件触发 → 该行业进入**备选**；
3. 对备选行业，按**各自触发事件的 IR 均值**降序排序，取 **IR 均值最大且 > 0** 的、**不超过 7 个**行业；
4. 对选中的行业**等权配置**；
5. **兜底**：当期**无有效行业**、或有效行业的 IR 均值**都 < 0** → **直接配置全部 28 个行业的等权组合**；
6. **只做多**行业指数、不做空 → 因此行业有效事件 **IR 均值 < 0 的行业不予考虑**。

## 5. 回测方法

| 项 | 设定 |
|---|---|
| 标的池 | **申万一级行业，共 28 个** |
| 样本区间 | **2009 年 1 月 ~ 2019 年 1 月**（11 年） |
| 调仓频率 | **月频**（1 个自然月）；每月**末交易日**为策略起点 |
| 开仓规则 | 行业有效事件库触发 → 按触发事件 IR 均值排序 → 取 ≤7 个（IR 均值>0）等权 |
| 平仓规则 | 月度调仓自然换出（**原文未给单独的止损/止盈**——无事件触发即不配置） |

| 基准 | **行业等权基准** |
| 评价指标 | 年化收益率、年化波动率、信息比率、超额收益 |

## 8. 与本工程的关联

- **主题同源**：与工程 `research-projects/industry _regime_stock_picking` 都是**行业轮动/行业配置**。
  但**行业层的信息源完全不同**：
  | | 本工程（变盘指数） | 本篇（宏观事件） |
  |---|---|---|
  | 行业层输入 | 行业指数的**内生**指标（排名迁移幅度的波动） | **外生**宏观/产业变量 |
  | 判据形态 | 连续量 T′ 符号（排序/开关） | **离散事件**（8 类极端状态） |
  | 标的 | 行业内的**个股** | **行业指数**本身 |
- **可直接借鉴的三点**：
  1. **「事件化」把连续指标离散成极端状态** —— 与本工程反复出现的「排序 ≫ 开关」定律形成**对照**：
     本文的「开关」之所以有效，是因为其**标的本身就是行业指数**（开关直接作用于被交易对象）；
     而本工程的教训是**用行业信息去开关个股**会失效。两者不矛盾，反而互相印证了那条定律的边界。
  2. **双门槛显式化显著性**（|IR|>0.7 且 发生次数≥8）—— 是「统计显著性」的显式门槛写法，
     可作为本工程给信号加「最小样本量 + 最小 IR」约束时的参考。
  3. **表6「行业 → 有效事件 × 期数」是一张现成的映射表**（28 行业全列），
     若将来引入宏观变量，可当作**初始假设来源**（而非直接照搬，因存在前视）。
- **不适用之处**：本工程当前**没有宏观/产业指标数据**（见 §7），且本工程走的是「行业→个股」的选股链，
  而本篇只到**行业层**（不做行业内选股）。
