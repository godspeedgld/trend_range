## 1. 研报背景

- 一个完整的行业轮动框架通常涵盖**自上而下**（宏观指标如 PMI、CPI、货币政策 → 行业中观指标）与
  **自下而上**（行业内个股、行业价量走势特征）两层。
- 作者的问题意识：**近几年行业之间的联动、产业链之间的传导特征加快**，研究更加细化，对行业/板块的
  细分提出了更高要求；而**传统的行业划分**（见表 1）是"人为"主动划分，**可能随市场状态特征、产业周期
  变化而调整不及时**。
- 因此提出：行业重新划分应从**行业相关的统计特征**出发，**从逻辑与理论上更注重行业间统计相关特征的
  显著性**，以更及时地捕捉行业轮动投资机会。

| 划分依据 | 划分类别 |

| 基于行业所处产业链阶段 | 上游、中游、下游等 |
| 基于行业状态特征 | 周期、成长等 |
| 基于行业对资源、资本等生产要素的依赖程度 | 劳动密集型、资源密集型、资本密集型、技术密集型等 |

## 3. 量化思路

**核心思路（原文 §五(一) 策略思想）**：

> 上下游行业或相似行业之间可能存在**短期的联动关系**，可以构建一个基于**动态行业聚类**的板块轮动策略：
> 利用**每个调仓点前的时间窗口**进行行业聚类，得到存在**短期联动关系的板块**，再利用**板块与行业的
> 关系**进行行业轮动，从而寻找投资机会。

拆成可交易的四个问题：

| 问题 | 原文回答 |
|---|---|
| **什么条件下触发** | 每期调仓日节点（周频），对**调仓日前 1 年**的行业收益率序列做聚类 → 得到当期板块划分 |
| **做什么方向** | 两条互为镜像的腿，**各测一条**：① **趋势跟踪** = 每个板块内选**当期收益率最高**的行业，等权持有；② **反转类** = 每个板块内选**当期收益率最低**的行业，等权持有 |
| **赚什么钱** | 趋势跟踪赚**行业上涨的惯性（动量）**——原文明确"认为行业的上涨趋势是具有惯性的"；反转类为对照腿 |
| **为什么成立** | ① 传统划分"人为、调整不及时"；② 从统计相关特征重新刻画行业**能更及时捕捉轮动机会**；③ 上下游/相似行业存在**短期联动**，同板块内选强/选弱可把"选行业"降维成"选板块 + 板块内选边际" |

**结构上的关键设计**：聚类把 28 个行业压成 **K=5 个板块**，策略在**每个板块内只选 1 个行业**
⇒ 天然形成"**跨板块分散**"（最多持仓 5 个行业，每板块 1 个）。**注意**：原文未讨论这一点是否是
有意的风险预算设计，仅作为策略定义给出。

## 4. 量化算法 / 指标

### 4.1 三种聚类方法（原文只做划分聚类与凝聚层次聚类的实证；DBSCAN 只介绍未实证）

**① K-Means**（目标：最小化样本点到聚类中心的距离之和）

```
E(X) = Σ_{i=1..k} Σ_{x∈π_i} ‖x − ν_i‖²          ν_i = (1/|π_i|) Σ_{x∈π_i} x
```

- `x` 数据集中的点；`ν_i` 第 i 类的聚类中心；`π_i` 第 i 类的点集；`k` 聚类数
- 步骤：随机选 K 个初始中心 → 按最小距离分配样本 → 用分类后数据点重算中心 → 重复至中心不变
- 原文自述不足：**对初始位置敏感**（多次聚类结果可能不同）、依赖人工设定 K、孤立点噪声干扰、
  非凸数据集效果差

**② 凝聚层次聚类**（自底向上：每个点自成一类 → 合并最近的类 → 重算类间距离 → 直到 K 类）

样本距离度量（原文表 2）：

| 度量 | 公式（原文，二维写法） |
|---|---|
| 欧氏距离 Euclidean | `D(x,y) = √((x₁−y₁)² + (x₂−y₂)²)` |
| 曼哈顿距离 Manhattan | `D(x,y) = |x₁−y₁| + |x₂−y₂|` |
| 余弦距离 Cosine | `D(x,y) = 1 − cos(θ) = 1 − (x·y)/(‖x‖‖y‖)` |

类与类之间的距离（原文表 3）：

| 方式 | 公式 |
|---|---|
| 单链 Single Linkage | `D(C₁,C₂) = Min D(X₁,X₂)` |
| 平均链 Average Linkage | `D(C₁,C₂) = (1/(|C₁||C₂|)) Σ_{x₁} Σ_{x₂} D(X₁,X₂)` |
| 全链 Complete Linkage | `D(C₁,C₂) = Max D(X₁,X₂)` |

原文经验：**有明显边界的数据单链较好；边界模糊时单链较差、平均链与全链较好**（图 2 引 scikit-learn）。

**③ DBSCAN**（基于密度）：核心点 → 密度可达点成簇；边缘点跳过。原文仅介绍算法与优缺点
（可任意形状、可识别异常点、起始点无关；但复杂度高、需联合调阈值），**未在本篇实证**。

### 4.2 ★ K-Means 的两项改进（本篇的技术重点）

**（a）核方法 → Kernel K-Means**（把样本映射到高维使线性可分）

- 传统欧式样本距离：`d(x_i,x_j) = ‖x_i − x_j‖₂ = Σ_{s=1..d}(x_is − x_js)²`（`s` 为特征维度下标）
- K-Means 的等价形式：`min_U Σ_{k=1..C} Σ_{i=1..n} U_ki ‖c_k − x_i‖₂²`
  （`c_k` 聚类中心；`U_ki` 类别归属指标，`x_i` 属第 k 类取 1 否则 0）
- 映射函数 `Φ(·)` 后的距离展开：`d(x_i,x_j) = Φ(x_i)'Φ(x_i) + Φ(x_j)'Φ(x_j) − Φ(x_i)'Φ(x_j) − Φ(x_j)'Φ(x_i)`
- 定义**核函数 = 高维内积**：`K(x_i,x_j) = Φ(x_i)'Φ(x_j)`
  ⇒ 样本距离 `d(x_i,x_j) = K(x_i,x_i) + K(x_j,x_j) − 2K(x_i,x_j)`
- 样本到第 k 个聚类中心的距离（`n(k)` = 第 k 簇样本数，`x_h` 为第 k 簇内任一样本）：

```
d(x_i, c_k) = ‖Φ(x_i) − (1/n(k)) Σ_{h=1..n(k)} Φ(x_h)‖²
            = K(x_i,x_i) − 2·(1/n(k)) Σ_h K(x_i,x_h)
              + (1/n(k)²) Σ_{h1} Σ_{h2} K(x_{h1}, x_{h2})
```

⇒ **只要能用核函数算任意两样本的高维内积，就能算所有距离**（核技巧，无需显式映射）。

原文表 4 常用核函数（照录）：

| 核函数 | 公式 |
|---|---|
| Cosine | `K(x,y) = (x yᵀ)/(‖x‖‖y‖)` |
| Linear | `K(x,y) = xᵀ y` |
| Polynomial | `K(x,y) = (γ xᵀ y + c₀)^d` |
| RBF | `K(x,y) = exp(−γ‖x − y‖²)` |

**（b）★ 匹配算法合并多次聚类结果**（针对 K-Means 初值敏感，提高稳定性——这是本篇最"可搬用"的部件）

```
步骤 1：利用随机初值进行多次聚类，得到多组聚类结果；
步骤 2：从 n=1 起，把「前 n 个聚类的合并结果 x」与「第 n+1 个聚类结果 y」合并：
        ① 对 x、y 的各类别做中心匹配，相似度指标：
             similarity_{i,j} = (c_i 与 c_j 共有行业数量) / (c_i 内行业数量 + c_j 内行业数量)
           （c_i ∈ x 的任意类别，c_j ∈ y 的任意类别）
        ② 用贪心算法取 similarity 矩阵中最大的数值做匹配（如 x 的 c_i 对应 y 的 c_j），
           重复至剩余类别一一匹配完毕；
步骤 3：完成类别匹配后，逐一对所有行业做归属统计，**选择归属次数最多的类别作为最终分类结果**。
```

> ★ 该相似度是**"交集 / 两集合大小之和"**（Jaccard 的变体：Jaccard = |∩|/|∪|，此处分母用和而非并），
> 原文**未说明取该形式的理由**，也**未说明重复聚类的次数**（原文未明确）。

## 8. 与本工程的关联

**本工程现状（对照用）**：`industry _regime_stock_picking` 的行业层 = 变盘指数 T′ 切风格 →
动量期取 `mom_240` 前 3 行业、反转期取 `mom_60` 后 3 行业（银河「变盘指数」，analysis_001/strategy_001），
**每行业选 2 只股**（"每行业 2 只"已被 strategy_003 证明是**风险预算载体**而非限制）。

**可能的用法**：
1. **板块分散约束**：本文的"每个板块内只选 1 个行业"是一种**结构性的跨行业分散机制**。本工程的
   top3 行业是"排序结果"，可能与 003 的教训同源——排序选出的 3 个行业可能高度同质（如同属周期），
   **用聚类板块约束"3 个行业须落在不同板块"** 是一个尚未测过的分散约束形态。
2. **板块中性化 / 分组基准**：聚类结果可作为行业层的**分组变量**（类似 analysis_015 行业热度研究里
   "横截面 = 行业身份证、必须行业内中性化"的思路），检验本工程 top3 选择是否只是在赌某个板块。
3. **方向相反要注意**：本文两条腿里**反转腿（买最弱）显著劣于等权**（超额 −20.50%），而本工程的
   选股层是"买超跌"（恒反转）、行业层是变盘指数切风格 —— **本文不能直接支持本工程**，
   但可作为"**在板块内买最弱**"的**反例证据**（与 analysis_018 广发微观篇「熊市选行业无信息」、
   analysis_016「反转周被过滤是过度保守」构成同一方向的阴性证据群）。
4. **可复用的两个部件**：① **匹配算法合并多次聚类结果**（提高聚类稳定性，K-Means 专用）；
   ② **敏感性分析的判据**（用"各类包含行业数量的均匀度 + 与真实走势的相关性是否合理"来选 K 与跨度
   —— 原文用"建筑装饰与钢铁同类但不合理"这种**人工合理性检查**，而非统计量，**注意这本身是样本内主观选择**）。
